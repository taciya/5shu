## 紫占模式

### 定义

关键字包含：

```text
问卦占事
```

时激活。

---

### 核心目标

侧重：

```text
瞬时能量
```

解决：

```text
单项事件
成败
虚实
应期
```

问题。

---

### 核心观察对象

三层卦：

```text
主卦
十分卦
分钟卦
```

---

### 权重原则

三层卦属于：

```text
现实显象层
```

定义：

```text
主卦   = 起因
十分卦 = 过程
分钟卦 = 结果
```

属于本卦最高权重。

---

### 分析流程

```text
三层卦
↓
三层卦飞化
↓
点亮结构
↓
星曜结构
↓
四化链
↓
现实显象
```

---

### 输出目标

回答：

```text
天地最终想表达什么
```

而非：

```text
哪个宫位看起来重要
```

## 点亮协议

### 点亮次数统计协议

点亮次数：

定义为：

> 被飞化直接命中的累计次数。

例如：

夫妻 → 父母

迁移 → 父母

官禄 → 父母

则：

父母宫点亮次数 = 3

---

### 点亮权重协议

#### 高点亮

3次及以上

定义：

核心运行节点。

必须重点分析。

---

#### 中点亮

2次

定义：

重要承接节点。

需要分析。

---

#### 低点亮

1次

定义：

辅助节点。

只用于补充结构。

不得单独定结论。

---

#### 未点亮

0次

定义：

背景静默层。

禁止纳入主线分析。

---

### 点亮优先级协议

同等条件下：

优先分析：

[紫占模式]: `三层卦` > 高点亮宫位 > 中点亮宫位 > 低点亮宫位 > 背景宫位

[命理模式]: `三才宫` > 高点亮宫位 > 中点亮宫位 > 低点亮宫位 > 背景宫位

---

禁止：

因为宫位象义看起来重要。

就跳过点亮权重。

例如：

问感情。

夫妻宫未被点亮。

即使夫妻宫天然相关。

也禁止强行解释夫妻宫。

---

### 背景宫位协议

未点亮宫位：

允许查看。

但仅允许作为：

> 背景资料。

不得：

- 参与主链裁断
- 参与最终结论
- 推翻已点亮结构
- 替代点亮宫位

即：

未点亮宫位只可辅助。

不可主导。

---

### 点亮输出协议

正式分析前：

必须先输出：

#### 点亮统计

高点亮：

（列出宫位）

中点亮：

（列出宫位）

低点亮：

（列出宫位）

未点亮：

（列出宫位）

---

然后：

按照点亮权重进入分析。

禁止直接开始裁断。

---

### 点亮最终铁律

点亮：

负责回答：

> 天地把能量运行到了哪里。

三层卦（三才宫）：

负责回答：

> 天地最终想表达什么。

两者职责不同。

禁止混用。

---

#### 三层卦与点亮关系

三层卦：

属于现实显象层。

定义：

- 起因
- 过程
- 结果

属于：

本卦最高权重。

---

点亮结构：

属于运行层。

定义：

- 能量经过哪里
- 能量放大在哪里
- 能量承接在哪里
- 能量收缩在哪里

属于：

三层卦的展开结构。

---

因此：

点亮不能决定：

最终显象。

只能解释：

最终显象如何形成。

---

例如：

主卦 = 夫妻宫

十分卦 = 财帛宫

分钟卦 = 兄弟宫

即使：

田宅宫被点亮10次。

交友宫被点亮8次。

也不得直接解释：

田宅宫。

交友宫。

而必须先解释：

夫妻
↓
财帛
↓
兄弟

形成什么现实显象。

之后：

再利用田宅宫、交友宫解释：

这条显象路径如何运作。

---

#### 点亮服从三层卦原则

正确顺序：

↓

三层卦飞化

↓

点亮结构

↓

星曜结构

↓

四化链

↓

现实显象

禁止：

高点亮宫覆盖三层卦。

禁止：

禁止：

因为某宫飞化很多，
而跳过三层卦。

禁止：

## 四化链协议

### 总原则

#### 1. 四化链独立原则

四化分为：

- 禄链
- 权链
- 科链
- 忌链

每条链独立运行。

禁止跨链追四化。

---

#### 2. 追四化原则

链路类型决定追四化类型。

- 禄链 → 只追禄
- 权链 → 只追权
- 科链 → 只追科
- 忌链 → 只追忌

定义：

追四化=四化→来源宫

目的：

> 确定该四化的发源宫

---

#### 3. 推进器原则

所有链路统一使用：

推进器 = 忌

定义：

```text
当前节点宫
↓
取本宫宫干飞忌
↓
到达下一宫
```

注意：

> 忌只负责推进
> 不改变链路性质。

例如：

> 科链

推进过程中：

> 每一步都使用飞忌

但：

> 链路仍然属于科链

---

#### 4. 四化汇聚原则

定义:
四化汇聚:

> 宫位推进时，
> 可以汇集该链路类型的所有能量一起带入下个节点

比如:

> [主三宫]→天机科→P1宫
> P1宫内同时还有太阴星
> 因为太阴星可以化科，所以通过追四化[科]，找到P1_3宫

当宫位通过宫干飞忌进行推进时:
推进器会带着以下两个信息进入下个宫位:

> 1.[主三宫]→天机科→P1宫
> 2.p1_3宫→天阴科→P1宫

## 小星成本函数

### 小星本质

小星不是单纯的附加说明，而是作用在主星路径上的成本函数。

```text
小星 = 场域特性（Field） + 运行机制（Mechanism） + 代价函数（Cost）
```

| 维度     | 含义                         | 裁断用法                                         |
| :------- | :--------------------------- | :----------------------------------------------- |
| 场域特性 | 该宫位的气候、环境、背景色   | 判断此宫是稳定、混乱、隐性、过度、缺失还是噪音场 |
| 运行机制 | 能量在此如何运作             | 判断路径是卡、快、绕、断、漏、散、变还是被遮蔽   |
| 代价函数 | 完成同一结果要额外付出的成本 | 判断时间成本、路径成本、认知偏差成本、结构风险   |

对齐规则：

- 大星定框架。
- 小星定细节。
- 四化定变化与应期。
- 小星负责把“细节”升级为可计算的效率、摩擦和结构风险。

### 小星模型

裁断时，所有小星必须先归入至少一种类型。
同一小星可因宫位、组合、问题域而兼具多类，但输出时要说明主导类型。

| 类型                       | 关键词                             | 代表星曜                                   | 通用规则                                 | 成本表现         |
| :------------------------- | :--------------------------------- | :----------------------------------------- | :--------------------------------------- | :--------------- |
| 阻力型（Resistance）       | 卡、拖、反复、消耗、噪音、低频干扰 | 陀罗、擎羊、铃星、阴煞                     | 使路径产生摩擦、卡顿、延迟或难以直接推进 | 时间成本上升     |
| 流动型（Variation）        | 变化、切换、多路径、不稳定、移动   | 天马、天机类结构、右弼                     | 使路径产生多路径、不稳定、转向或持续变动 | 路径成本上升     |
| 染色型（Marker）           | 真假、情绪、标签、名相、隐性性质   | 天虚、天喜、病符、文曲忌、红鸾、咸池、天姚 | 改变结果性质，不优先改变路径结构         | 认知偏差成本上升 |
| 击穿型（Structural Break） | 断裂、崩塌、缺失、耗尽、结构改写   | 地劫、天空、大耗、截空、丧门               | 直接改变结构，不只是过程修饰             | 结构风险上升     |

补充归类：

| 星曜 | 默认类型         | 说明                                         |
| :--- | :--------------- | :------------------------------------------- |
| 地空 | 染色型 / 击穿型  | 轻则过度、多余、鼓起；重则空亡、结构空转     |
| 地劫 | 击穿型           | 本应有而没有，坑洞、断裂、缺口               |
| 火星 | 流动型 / 阻力型  | 速度、温度、光亮；过强时造成急躁、过热、灼伤 |
| 文昌 | 染色型 / 流动型  | 传播路径、偏斜、文书载体                     |
| 文曲 | 染色型           | 内容性质、文字数据、契约内容                 |
| 左辅 | 流动型           | 数量增加、多条路径、多层辅助                 |
| 右弼 | 流动型           | 转向、更新、再一次、路径改变                 |
| 禄存 | 击穿型 / 阻力型  | 块状堆积，可能形成堵塞或沉重成本             |
| 解神 | 击穿型的反向修复 | 分解、解除、终止旧结构                       |
| 天刑 | 阻力型 / 击穿型  | 规则切割、手术、惩罚、可控伤害               |

### 成本公式

```text
最终表现 = 四化方向 × 主星承载 × 落点宫位容器 × 小星修饰系数
```

其中：

```text
小星修饰系数 = 场域特性 + 运行机制 + 成本类型
```

裁断时不得只说“小星不好”。
必须说清楚它增加了哪一种成本。

### 小星+四化

#### 化禄：扩散与放大

```text
收益路径 = 化禄 ×（主星当前状态）×（1 - 阻力 + 变动 + 染色）
```

| 小星类型 | 对化禄的作用                                       |
| :------- | :------------------------------------------------- |
| 阻力型   | 收益变慢，资源进入但兑现延迟                       |
| 流动型   | 收益不稳定，资源路径多变或分散                     |
| 染色型   | 收益性质改变，可能变成情绪收益、名义收益、虚假收益 |
| 击穿型   | 放大缺口、空耗、断裂或结构性漏失                   |

示例：

- 太阴铃星化禄：储存的烦恼被放大，收益表现为“苦水增加”。
- 天机地劫化禄：运动空耗被放大，越动越白费力气。
- 贪狼地劫化禄：欲望被放大，但实际满足有缺口。

#### 化权：推进与施压

```text
推进路径 = 化权 ×（主星执行力）×（路径偏移 + 阻力 + 结构承压）
```

| 小星类型 | 对化权的作用                         |
| :------- | :----------------------------------- |
| 阻力型   | 推进卡顿，越推摩擦越大               |
| 流动型   | 推进方向变化，可能转向、换人、换路径 |
| 染色型   | 推进带有标签、情绪、名相或误判       |
| 击穿型   | 强制重构，可能直接改写结构           |

示例：

- 破军地劫化权：强行动作打到缺口上，突破可能变成结构重写或突破失败。
- 巨门地劫化权：强行打开通道，但通道本身有洞，易变成权限/沟通漏洞。

#### 化科：修正与缓冲

```text
修正路径 = 化科 ×（延迟 + 多轮修正 + 信息化）
```

| 小星类型 | 对化科的作用                         |
| :------- | :----------------------------------- |
| 阻力型   | 修正变慢，流程拖延                   |
| 流动型   | 反复修正，多次变更版本或路径         |
| 染色型   | 修正偏表面、名义、文书、标签化       |
| 击穿型   | 修正结构缺口，若承载不足则只留下补丁 |

示例：

- 巨门地劫化科：漏洞进入解释、修复、文书化流程，但速度慢。
- 文曲忌遇科：内容层面被修正，但容易停留在名相或文本表面。

#### 化忌：收缩与终止

```text
收缩路径 = 化忌 ×（当前状态终止）×（小星成本放大）
```

| 小星类型 | 对化忌的作用                   |
| :------- | :----------------------------- |
| 阻力型   | 问题拖长，终止过程不干脆       |
| 流动型   | 问题扩散，终止点移动或路径外溢 |
| 染色型   | 问题性质被误读，容易贴错标签   |
| 击穿型   | 直接崩塌、断裂、清空或结构终止 |

示例：

- 七杀地劫化忌：线性缺口被触发为断线节点，发展线中断。
- 天机陀罗化忌：运动/思维被反复缠住后终止，表现为卡住很久才停。

### 小星组合原则

任意小星组合都按场域叠加处理，不得只背固定组合。

```text
小星组合 = 场域叠加（Field Overlay）
最终场域 = ∑（各小星场域特性）
```

示例：

```text
流动型（天马） + 阻力型（陀罗）
= 变化中卡顿
= 多路径 + 摩擦
= 曲线推进结构
```

裁断输出：

> 该路径并非完全不能动，而是在变化中反复卡住，需要绕行、等待或多次调整。

### 成败裁断

```text
结果 = 四化方向（主导）
      × 主星能级（承载）
      × 落点宫位（容器）
      × 小星成本（效率/代价）
```

小星阻力不必然导致失败。
若满足以下条件，阻力可转化为筛选、优化、训练或防错机制：

```text
四化 ∈（化禄 / 化权 / 化科）
AND 主星能级 ≥ 平
AND 落点宫位可承载
AND 所问目标允许延迟、试错或多轮修正
```

转化规则：

| 小星成本     | 可转化为                       |
| :----------- | :----------------------------- |
| 时间成本     | 筛选机制、训练周期、沉淀过程   |
| 路径成本     | 多方案试错、路线优化、转向机会 |
| 认知偏差成本 | 标签校正、名义确认、信息澄清   |
| 结构风险     | 重构机会、止损点、旧结构清除   |

若不满足承载条件，小星成本会从“修饰”升级为“拖垮路径”的主导因素。

### 输出模板

裁断中必须使用以下句式之一：

```text
该路径在【宫位】中，受【小星类型】影响，
表现为【运行机制】，从而增加【成本类型】。
```

```text
该星曜原始成像为【主星图像】，
小星将其修饰为【细节图像】，
四化再使该图像进入【放大/推进/修正/终止】状态。
```

示例：

> 该路径在官禄宫中，受阻力型小星影响，表现为反复卡顿，从而增加时间成本。

> 天机原始成像为运动路径，陀罗将其修饰为绕圈与缠住，化忌再使该路径进入反复卡住后的终止状态。

### 禁止

- 禁止把某个小星固定为“坏”。
- 禁止把某个小星固定为“好”。
- 禁止把某个组合当作唯一结构，例如只认“天马 + 陀罗”。
- 禁止忽略小星类型分类直接下结论。
- 禁止只说“有阻碍”，必须说明阻碍属于时间成本、路径成本、认知偏差成本还是结构风险。
- 禁止小星越级覆盖主星；除非击穿型小星已经造成结构重写。

## 显象协议

### 定义

紫占：

不是吉凶系统。

而是：

```text
天地现实运行状态描述系统
```

---

### 唯一合法来源

现实显象必须来自：

```text
宫位
+
星曜
+
四化链
+
点亮
```

共同形成。

---

### 宫位原则

宫位：

```text
是场景
不是结论
```

禁止：

```text
父母宫 = 联系
夫妻宫 = 恋爱
财帛宫 = 赚钱
```

直接映射。

---

### 星曜原则

星曜：

```text
不是吉凶
不是人格
```

而是：

```text
物理结构
运行方式
状态特征
```

---

### 四化原则

四化：

```text
不是结论
```

只能作用于：

```text
星曜原始星意
宫位场景
庙旺落陷
问题目标
```

---

### 显象生成公式

```text
宫位场景
+
星曜模型
+
四化链
+
点亮路径
=
现实显象
```

---

### 输出铁律

若卦象没有直接表达：

必须输出：

```text
卦象未表达
```

禁止：

```text
补完答案
脑补答案
推测答案
```
