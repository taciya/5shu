# 六十四卦图象解知识库

## 1. 乾为天

| 六十四卦 | 原图核心                                             | 象义                                                                                                                    | 记忆                                                                                   |
| -------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 乾为天   | 官人在梯上、云中鹿、发光玉石、磨玉人、工匠、官人回望 | ①平步青云。②不求禄而禄自来。③人才待时发光。④功成仍需磨炼。⑤可自立门户创业。⑥盛极易衰。⑦升迁后须戒骄戒争，否则旦夕而败。 | 官员沿天梯登天，云中有鹿（禄）相迎；脚下工匠磨玉提醒：越往高处越要修身，否则跌落更快。 |

## 2. 坤为地

| 六十四卦 | 原图核心                         | 象义                                                                             | 记忆                                               |
| -------- | -------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------- |
| 坤为地   | 厚土、妇人、牛马、田园、承载万物 | ①顺势而行。②以柔克刚。③利辅佐不利争先。④包容承载。⑤守成优于开创。⑥积累终有收获。 | 大地沉默无言，却承载万物；牛马勤耕，最终仓廪丰足。 |

## 3. 水雷屯

原文：人立望竿、犬、车陷泥、牛回头、射文书、合盒等。

| 六十四卦 | 原图核心                                   | 象义                                                                                      | 记忆                                                                 |
| -------- | ------------------------------------------ | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 水雷屯   | 望竿、人立、犬、泥车、牛回头、射文书、合盒 | ①创业艰难。②局势未明。③进退两难。④小人阻碍。⑤贵人在侧但未发力。⑥逆向而行反吉。⑦先成后破。 | 车陷泥坑，主人站高处观察局势；牛回头等待时机，狗在旁边狂叫提醒危险。 |

## 4. 山水蒙

原文：满船珍宝、船、鹿、两串钱、碗、李树折枝。

| 六十四卦 | 原图核心                           | 象义                                                                               | 记忆                                                         |
| -------- | ---------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 山水蒙   | 宝船、水船、鹿、双钱、碗、折枝李树 | ①图财而受蒙蔽。②远行求财。③虽有禄而不安。④财来路不正。⑤得财快失财亦快。⑥先成后破。 | 装满珍宝的大船离乡而去，船主忙着数钱，却不知船底已开始漏水。 |

## 5. 水天需

原文：明月、门、攀龙尾、僧人、墓。

| 六十四卦 | 原图核心                       | 象义                                                                       | 记忆                                                         |
| -------- | ------------------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 水天需   | 明月、门户、攀龙尾、僧人、墓地 | ①等待时机。②依附贵人。③不可躁进。④置之死地而后生。⑤静守化险。⑥修心可避灾。 | 一个人抓住龙尾不敢放手，和尚在旁说：再等一等，天亮自然过去。 |
