# 01\_定义层

## 宫位根定义

宫位：

不是结果。

宫位：

只是：

现实发生场景。

---

### 我宫

解决的问题：

- 这件事属于谁？

是主体归属判断。

我宫,包括:

- 命宫
- 财帛宫
- 疾厄宫
- 官禄宫
- 田宅宫
- 福德宫
- 迁移宫

口诀：
命财官田福疾迁 = 我宫

其余：
兄弟、夫妻、子女、交友、父母 = 他宫

---

#### 我宫的用途

我宫本质上用于：

##### 1 判断得失归属

河洛派原文：

- 他宫禄入我宫，我得。
- 我宫禄入他宫，我失。
- 他宫忌入我宫，我受损。
- 我宫忌入他宫，他受损。

例如：

```text
交友宫化禄入财帛
```

先不看别的。

因为：

```text
交友 = 他宫
财帛 = 我宫
```

所以：

```text
别人给我利益
```

---

如果：

```text
财帛化禄入交友
```

则：

```text
我给别人钱
```

---

##### 2 判断谁影响谁

例如：

```text
夫妻宫使命宫化忌
```

夫妻宫是他宫。

命宫是我宫。

所以：

```text
配偶影响我
```

---

##### 3 判断利益流向

例如：

```text
父母宫禄入迁移
```

父母是他宫。

迁移是我宫。

结论：

```text
外来资源进入我
```

---

因此：

###### 看到四化

第一步永远先问：

```text
起点是谁？
终点是谁？
```

这里用的是：

```text
我宫/他宫体系
```

### 内宫

解决的问题：

- 这件事处于哪个层次？

是状态层次判断。

内宫,包括:

- 命宫：
  自己、内、根本、累生、源头、气运上的我

- 田宅宫：
  内核、天魂、潜意识、本质

- 福德宫：
  思想、感觉、心情、精神状态

- 疾厄宫：
  现实、身体、肉身状态

命宫→我是
田宅宫→为什么这样
福德宫→怎么想的
疾厄宫→什么样

---

#### 内宫的用途

内宫不管谁得谁失。

它研究：

```text
事情发生在哪个层面
```

---

例如：

##### 命宫

代表：

```text
内因
```

---

##### 田宅

代表：

```text
内核
```

---

##### 福德

代表：

```text
思想
```

---

##### 疾厄

代表：

```text
现实表现
```

---

例如：

```text
命宫巨门化忌
```

这里不需要讨论我宫。

因为命宫本来就是我宫。

你真正要问：

```text
这个忌发生在哪个层次？
```

答案：

```text
命宫
```

所以：

```text
根本状态出问题
```

---

如果：

```text
福德宫巨门化忌
```

则：

```text
思想层出问题
```

---

如果：

```text
疾厄宫巨门化忌
```

则：

```text
现实层出问题
```

### 命宫

核心/发心接口 (主体性质)。

- 自己，气运，灵魂，我，魄力，业力，神识
- 命数，气数，宿缘，宿命，命名，使命，寿命
- 先天根基，个性本质，第一驱动力
- 与疾厄宫一体两面：命主精神，疾厄主肉体

---

### 财帛宫

可兑现资源流/筹码接口 (资产价值性质)。

- 钱财，资源，价值评估，盈亏，筹码
- 智商，情商，财务报表，赚钱能力，现钞

---

### 官禄宫

行为/逻辑接口/规则运行系统/现实流程推进层 (行为运作性质)。

• 行为，运作逻辑，制度，功名，社会地位
• 职位，管理，秩序，职业生涯，目的性

---

### 子女宫

输出物 / 结果物/ 结果产出/产出接口 (行为执行性质)。

• 下属，徒弟，粉丝，成果，子公司，变动
• 桃花位，性能力，分娩，创造力，投资位

---

### 父母宫

审核 / 权限系统/规则/秩序接口 (文书上层性质)。

• 上级，政府，规则，秩序，文书，证明
• 法律，信用，背书，官方，背景，名位

---

### 兄弟宫

同层竞争体/内部/协作接口 (资源周转性质)。

• 同行，同事，竞争，手足，现金周转，财库
• 母亲，盟友，契约，弟子，成就线（官禄之疾）
• 床位：同居生活的基础，身体的气数体质

---

### 交友宫

外部群体接口/众生/市场接口 (外部推力性质)。

• 众生，客户，市场，社群，对比，推力
• 小人，竞争对手，粉丝，别人的钱袋子

---

### 迁移宫

外部变量/空间/反馈接口 (环境结果性质)。
当前事件脱离现状以后，所要去的地方。
• 结果态,环境，社会评价，外界，机遇
• 出行，变动，漂泊，社会空间，人生反馈
• 过去/未来,未知空间

---

### 福德宫

内部意识/心念/因果接口 (潜意识能量性质)。

• 想法，潜意识，心情，心念，慧根，福报
• 理想化，业力反馈，精神享受，源动力

---

### 田宅宫

空间容器/资产/终局接口 (储存基础性质)。

• 祖产，资产库，终局，家底，财库，根基
• 积累，空间，私域，潜藏资源，储存点

---

### 疾厄宫

内部运行/现象/现场接口 (肉身显化性质)。

• 肉体，病灶，现场，物理状态，显化
• 底层运作，器官，免疫，创伤，身体信号

---

### 夫妻宫

绑定关系/对待/契约接口 (博弈对待性质)。

• 因果位，对方，对手，对待位，博弈位
• 婚姻，契约另一方，合作关系，结果，情债
• 一切二元关系：我与外界的“博弈面”

### 四化 + 组合

示例：

- 七杀地劫化忌：线性缺口状态被终止，可能表现为断线节点明确、该线停用、发展线中断。

## 能级(星曜亮度)根定义

能级 = 显像强度与现实穿透力。

能级 ≠ 吉凶分数。

高能级 = 更容易显化、更难忽略、更能压制低能级结构。

低能级 = 显像弱、物理化慢、受干扰多。

低能级 ≠ 无效。

若低能级作用于关键宫位、关键星曜、关键四化或高权重现实中断层：

仍必须进入主线分析。

能级(星曜亮度)：

属于：

> 星曜现实承载能力。

能级(星曜亮度)只负责：

- 兑现稳定度
- 承载上限
- 波动风险
- 是否容易被忌击穿

所以,能级(星曜亮度)的影响表现形式可能有:

- 庙(7)/旺(6):根基浑厚,可以充分发挥该星曜优势,吉星则越吉,凶星也能发挥其正面力量(比如擎羊:果敢突破力强),哪怕遇到不利四化影响,仍可保证基本稳定度.
- 利(5)/得(4)/平(3):无特别之处
- 不(2)/陷(1):根基不稳,哪怕吉星吉华也会可能呈现负面效果(比如过犹不及,禄:过于乐观,权:计较/暴躁,科:优柔寡断)

特殊处理:
因为 忌=终止/收藏 所以:
遇到忌的时候:

- 庙(7)/旺(6):短期受影响,出现不顺,但星曜本身不会崩盘.需要结合宫位本身特性来看得失吉凶
- 利(5)/得(4)/平(3):无特别之处
- 不(2)/陷(1):极容易结构性崩盘.但也可能因此被迫重组,甚至短期触底反弹.但需要看最终宫位承受力,否则也是昙花一现.

- 能级不是吉凶，而是承载力、速度、完整度、可持续度。

| 化忌 | 强制制动，压力可消化，状态可切换 | 部分阻断，需看应期 | 系统停摆、承载击穿、路径中断         |

#### 能级+星曜

| 星曜 | 庙旺                           | 平利                           | 落陷                         |
| :--- | :----------------------------- | :----------------------------- | :--------------------------- |
| 天机 | 高速运动、思维活跃、路径清晰   | 局部移动、短期变化、路径需验证 | 低速、卡顿、宕机、动不起来   |
| 太阳 | 高亮、可见、外参有力、说服力强 | 局部照见，有盲区               | 遮蔽、黑箱、误导、信心不足   |
| 太阴 | 储存稳定、容量足、持续性强     | 局部储存，需看组合             | 存不住、漏、夜/水/情绪失衡   |
| 七杀 | 长线完整、线性结构清楚         | 局部线段、短线                 | 断续、虚线、片面、线性不足   |
| 天府 | 空间稳定、边界完整             | 区域可用但需补强               | 空间不足、边界虚、区域缺失   |
| 铃星 | 稳定警示、可识别信号           | 背景噪音、间歇焦虑             | 噪音折磨、误读信号、持续烦恼 |

| 天才 | 高效推演、计划有用             | 常规修正                       | 空想、算计失效               |
| 阴煞 | 隐性护持、直觉提示             | 微小扰动、查不清               | 查不到的阻力、看不见的问题   |

## 四化根定义

### 1. 四化总表

| 四化 | 核心动作                                 | 物理模型                         | 裁断口径                                                                                 |
| :--- | :--------------------------------------- | :------------------------------- | :--------------------------------------------------------------------------------------- |
| 化禄 | 放大当前状态、投入、扩散、资源增加       | 趋势被加速或被放大               | 不判断“好”。先问当前状态是什么，再判断放大后是否支持目标。                               |
| 化权 | 推动或压制、主导介入、碰撞、施压、控制   | 外力介入、杠杆、摩擦、强制执行   | 先判定谁飞权、飞向哪里、主体是否顺势。有承载为推动/执行；逆势、见忌或高压则为压迫/反噬。 |
| 化科 | 延缓、回退、修正、化解、蓄满、点亮       | 信息载体、缓冲层、修复机制       | 最显著特性是慢。可表现为文书、公示、背书、缓冲、慢慢转变。                               |
| 化忌 | 终止当前状态、收缩、断点、制动、不再扩张 | 状态被切断、运动被停止、路径终结 | 不判断“坏”。若目标需要终止，则化忌完成目标；若目标需要持续，则化忌阻断目标。             |

### 2. 化禄

化禄的基本公式：

> 化禄 = 放大原始星意 + 放大当前能级 + 增加该宫事项的投入。

必须先判断当前状态：

| 当前状态             | 化禄后                                       |
| :------------------- | :------------------------------------------- |
| 高能级、目标需要持续 | 推进、扩张、资源注入                         |
| 高能级、目标需要停止 | 过度推进、难以停下                           |
| 低能级、目标需要持续 | 放大低效、放大慢、虚胖、资源漏失             |
| 低能级、目标需要停止 | 低效状态被放大后，可能反而暴露问题并进入调整 |

示例：

- 天机庙旺化禄：运动/思维/技术路径加速。
- 天机落陷化禄：低速状态被放大，可能不是快，而是更明显地慢、卡、绕。
- 太阴化禄：储存内容被放大；储存快乐则快乐放大，储存烦恼则烦恼放大。

### 2.1 禄 × 星曜亮度 新规则

高亮度 + 禄：

不等于一定稳定。

低亮度 + 禄：

也不等于一定虚弱。

因为：

禄的本质：

是：

持续扩张。

真正要判断的是：

这个系统：

是否有能力承接扩张。

---

#### 第一类：稳定承接型扩张

若同时满足：

- 主链稳定
- 有兑现层承接
- 无严重忌击穿
- 权为推动而非高压
- 结构完整
- 星曜亮度稳定
- 扩张速度合理

则：

禄会形成：

- 稳定增长
- 长期积累
- 可持续兑现
- 资源沉淀
- 现实留存
- 真正的扩容

---

#### 第二类：泡沫型扩张

若同时满足：

- 禄过度集中
- 无兑现承接
- 高压权结构
- 忌持续漏损
- 星曜失衡
- 落陷仍被强行放大
- 多宫同时扩张
- 空劫同步存在

则：

禄会形成：

- 泡沫
- 虚胖
- 过度欲望
- 无效扩张
- 资源堆积失控
- 负担增长
- 反噬
- 后期坍缩

---

### 2.2 禄 × 落陷 新规则

落陷 + 禄：

不一定是好。

因为：

落陷代表：

原结构本身不稳定。

此时：

禄会把：

“不稳定结构”

继续放大。

因此：

可能形成：

- 欲望过度
- 虚假繁荣
- 错误持续扩张
- 资源失控
- 情绪膨胀
- 无法停止
- 越积越危险

但：

若同时存在：

- 新结构承接
- 科修正
- 权推动落地
- 主链完整
- 忌未击穿兑现层

则：

落陷禄也可能形成：

- 低位积累
- 缓慢恢复
- 弱系统增生
- 长期修复式成长
- 从低能级开始重建

注意：

这不是“禄自动变吉”。

而是：

扩张后的系统，
是否真的能承载增长。

---

### 2.3 禁止错误映射

禁止：

- 禄一定好
- 禄多一定强
- 禄多一定排名高
- 禄一定赚钱
- 禄一定能兑现
- 禄一定能留下来

因为：

扩张：

本身不代表：

稳定。

很多时候：

真正危险的，

不是“没有扩张”。

而是：

错误结构被持续放大。

---

### 2.4 禄的最终裁断原则

化禄最终必须检查：

#### 1）扩张的是什么

#### 2）谁在承接扩张

#### 3）扩张是否已经超过承载极限

#### 4）扩张后是否真正留下兑现

必须检查：

- 是否有兑现层承接
- 是否存在持续漏损
- 是否形成泡沫
- 是否形成依赖
- 是否只是短期膨胀
- 是否存在真实沉淀
- 是否形成长期留存

---

### 2.5 禄的最终铁律

禄代表系统扩张。

扩张后的结果：

可能是积累，
也可能是膨胀。

真正决定最终结果的：

不是“有没有禄”。

而是：

扩张后，
系统是否仍具备真实承接能力。

### 3. 化权

化权的基本公式：

> 化权 = 现实主导力介入 + 推动/压制分流 + 摩擦 + 控制权测试。

化权不是固定增强。真正判断是：

- 推动
- 还是压制

判断顺序：

| 判断项       | 含义                                 |
| :----------- | :----------------------------------- |
| 谁飞权       | 谁在主导现实                         |
| 飞向哪里     | 压谁 / 推谁                          |
| 来源宫角色   | 是主体力量，还是规则、制度、外部系统 |
| 是否竞争问题 | 是否进入筛选、排名、互卷系统         |
| 主体是否顺势 | 顺势则推进，逆势则压制               |
| 是否形成高压 | 是否进入强控、强筛、强摩擦           |
| 是否有忌     | 有忌时，权更容易从推动变成压迫       |

落地判断：

| 条件                                   | 化权表现                     |
| :------------------------------------- | :--------------------------- |
| 主体顺势、宫位能承载、目标需要推进     | 推动、执行、启动、落地       |
| 来源为官禄/父母/规则系统，且主体被筛选 | 压制、审核、强控、排名压力   |
| 竞争问题中多权同步                     | 高压互卷、强筛、强摩擦       |
| 同时见忌或忌已击穿承接面               | 权更容易变成压迫、反噬、卡控 |

示例：

- 贪狼化权：欲望/抓取增强，但需判断是主体主动抓取，还是被欲望/资源系统压迫。
- 破军化权在火位：突破动作强，若阻力过高则成为强压、硬撞或结构重写。
- 天同化权在水位：若顺势可被推动同意；若逆势则表现为被迫、勉强、压力下妥协。
- 太阳化权在水位：外部关注被强行拉起，但若承载不足，容易短暂显化后失去热度。

### 3.1 权 × 星曜亮度 新规则

高亮度 + 权：

不一定是推动。

低亮度 + 权：

也不一定无力。

因为：

权的本质：

是：

“现实控制力”。

真正要判断的是：

这股控制：

是在：

推进现实，

还是：

压迫现实。

---

#### 第一类：推动型权

若同时满足：

- 主链稳定
- 权顺势运行
- 有兑现层承接
- 忌未严重击穿
- 权用于执行
- 权用于推进现实
- 结构本身正确

则：

权会形成：

- 推进
- 落地
- 执行
- 强行动力
- 现实穿透
- 节奏加速
- 有效组织
- 资源调度

---

#### 第二类：压制型权

若同时满足：

- 高竞争环境
- 忌持续存在
- 权进入兑现层
- 权来源于规则系统
- 权形成单向控制
- 权压缩他人空间
- 无禄承接
- 主链失衡

则：

权会形成：

- 高压
- 内卷
- 强筛选
- 压迫
- 失衡竞争
- 强制淘汰
- 被规则碾压
- 现实窒息感

---

### 3.2 权 × 落陷 新规则

落陷 + 权：

不一定弱。

反而：

很多时候代表：

“失衡系统中的强制控制”。

因为：

落陷代表：

原结构已经不稳定。

此时：

权会强行维持、
强行推进、
强行控制。

因此：

可能形成：

- 高压维稳
- 强撑
- 硬推进
- 透支
- 被迫执行
- 失衡中的强控制
- 表面稳定
- 内部高摩擦

但：

若同时存在：

- 新主链形成
- 禄提供承接
- 科帮助显化协调
- 权用于纠偏
- 忌未击穿兑现层

则：

落陷权也可能形成：

- 强制改革
- 被迫成长
- 极限推进
- 在压力中完成现实转向
- 从失衡中建立新秩序

注意：

这不是“权自动变强”。

而是：

系统失衡后，

是否仍有人能控制现实。

---

### 3.3 权 × 竞争类 特别规则

竞争问题中：

权：

必须优先检查：

- 权来自谁
- 权压向谁
- 谁掌握规则
- 谁掌握筛选权
- 谁拥有现实定义权

因为：

竞争里的权：

很多时候不是：

“主体更强”。

而是：

“主体正在被更强规则压缩”。

因此：

可能出现：

- 能力很强但被规则压制
- 很努力但被高压筛掉
- 有发挥但无空间
- 被制度强控
- 被竞争节奏拖死
- 被现实不断加压

竞争类中：

权：

优先级高于：

科与禄。

因为：

现实里：

真正决定兑现空间的，

往往是：

谁拥有现实主导权。

---

### 3.4 权 × 忌 联动规则（新增关键）

权遇忌时：

必须优先检查：

这是：

#### 1）强控制下的崩塌

还是：

#### 2）强控制下的纠偏

若：

- 权持续压缩
- 忌进入兑现层
- 无禄承接
- 主链断裂

则：

容易形成：

- 高压崩塌
- 透支
- 被压死
- 强控失衡
- 内部瓦解

但若：

- 权用于修正
- 权推动新结构
- 忌是在去泡沫
- 禄形成新承接

则：

可能形成：

- 强制改革
- 断尾求生
- 高压转型
- 被迫成熟
- 极限纠偏

---

### 3.5 禁止错误映射

禁止：

- 权一定强
- 权一定赢
- 权一定高排名
- 权一定推进
- 权一定优秀
- 权一定有优势

因为：

控制：

本身不代表：

兑现。

很多时候：

真正危险的，

不是“没有权”。

而是：

失衡结构中的过度控制。

---

### 3.6 权的最终裁断原则

化权最终必须检查：

#### 1）谁拥有现实主导权

#### 2）权是在推进还是压制

#### 3）权是否形成高压失衡

#### 4）权之后是否仍存在真实兑现

必须检查：

- 权来源
- 权去向
- 是否形成规则压制
- 是否存在高竞争
- 是否有禄承接
- 是否有忌漏损
- 是否形成现实闭环
- 是否只是强行维稳

---

### 3.7 权的最终铁律

权代表系统主导。

主导后的结果：

可能是推进，
也可能是压迫。

真正决定最终结果的：

不是“有没有权”。

而是：

主导之后，

系统是否仍存在真实承接与兑现。

### 4. 化科

化科的基本公式：

> 化科 = 慢 + 修正 + 信息化/名相化 + 缓冲保护。

常见四类表现：

1. 延缓：事情拖慢。
2. 回退：资金、动作、态度回退。
3. 化解：冲突被缓冲、压力被卸掉。
4. 蓄满：慢慢积累到可转变。

特殊规则：

- 化科在水位/木位力量强，在火位/金位较无力。
- 水位/木位化科常需要很长时间才能完成转变。
- 左辅科、右弼科多为激活作用，不宜过度解释。
- 文曲科意义相对有限，偏点亮内容。
- 紫微化科凸显紫微优势；紫微化权反而要检查弱势暴露。

### 4.1 科 × 星曜亮度 新规则

高亮度 + 科：

不等于一定真实优秀。

低亮度 + 科：

也不等于没有影响力。

因为：

科的本质：

是：

“被看见”。

真正要判断的是：

被看见之后：

现实是否真的承接。

---

#### 第一类：真实显化型

若同时满足：

- 主链稳定
- 有兑现层承接
- 科与禄权形成闭环
- 忌未击穿
- 星曜结构稳定
- 显化内容与现实一致

则：

科会形成：

- 真正认可
- 稳定口碑
- 长期名义
- 真实传播
- 有效曝光
- 被持续看见
- 名实相符

---

#### 第二类：虚显型 / 失真型

若同时满足：

- 无兑现承接
- 科独立悬浮
- 忌持续漏损
- 空劫同步
- 落陷仍强行显化
- 权形成高压包装
- 主链不稳定

则：

科会形成：

- 虚名
- 假曝光
- 表面优秀
- 被包装
- 被营销
- 名实不符
- 只被看见但无法兑现
- 舆论化存在

---

### 4.2 科 × 落陷 新规则

落陷 + 科：

不一定是差。

因为：

落陷代表：

原结构不稳定。

此时：

科会把：

“不稳定状态”

直接显化出来。

因此：

可能形成：

- 缺点暴露
- 弱点公开
- 被放大审视
- 问题被看见
- 情绪被传播
- 失衡被显化

但：

若同时存在：

- 科后有禄承接
- 权推动修正
- 新主链形成
- 忌未击穿兑现层
- 结构开始重组

则：

落陷科也可能形成：

- 被看见后的修正
- 被发现后的改善
- 弱点公开后的成长
- 从隐藏问题进入真实调整
- 从压抑转向表达

注意：

这不是“科自动变好”。

而是：

显化后的系统，
是否真正进入有效现实。

---

### 4.3 科 × 竞争类 特别规则

竞争问题中：

科：

不等于排名。

科只代表：

“被看到”。

因此：

可能出现：

- 很显眼但排名不高
- 很有话题但兑现很差
- 被老师注意但成绩一般
- 被公司看见但最终未录取
- 被传播但未成交

竞争类最终必须检查：

- 是否有兑现层承接
- 是否有忌压缩
- 是否只是曝光
- 是否只是名义进入
- 是否真正留下有效兑现

---

### 4.4 禁止错误映射

禁止：

- 科一定高分
- 科一定前列
- 科一定优秀
- 科一定被认可
- 科一定成功
- 科一定兑现

因为：

显化：

本身不代表：

真实实力。

很多时候：

真正危险的，

不是“不被看见”。

而是：

被提前过度显化。

---

### 4.5 科的最终裁断原则

化科最终必须检查：

#### 1）什么被显化

#### 2）谁在看见

### 4.6 科的最终铁律

科代表系统显化。

显化后的结果：

可能是认可，
也可能是失真。

真正决定最终结果的：

不是“有没有科”。

而是：

显化后，
是否仍存在真实兑现与承接。

### 5. 化忌

化忌的基本公式：

> 化忌 = 终止当前状态 + 定应期 + 触发状态反转。

化忌不是“坏”，而是状态终止。

| 所问目标     | 化忌表现                       |
| :----------- | :----------------------------- |
| 目标需要继续 | 停止、断开、卡住、终止当前趋势 |
| 目标需要停止 | 制动、止损、结束、解除当前状态 |
| 原状态良好   | 良好状态终止                   |
| 原状态不佳   | 不佳状态终止，可能转入改善窗口 |

示例：

- 天机化忌：运动/发展/思维路径终止，可用于断应期。
- 交通事故场景：需要刹车时，天机化忌是制动完成。
- 学习状态：天机庙旺表示学习能力强、思维活跃；化忌则学习停滞、思维中断。
- 大运天机化忌可反推人生重大变化期。

---

### 5.1 忌 × 星曜亮度 新规则

星曜亮度落陷：

不是“差”。

而是：

星曜原始结构已经无法稳定维持。

因此：

当“落陷 + 忌”出现时：

代表：

原结构进一步进入压缩与失衡。

但：

压缩后的结果并不固定。

必须区分：

#### 第一类：失稳崩塌

若同时满足：

- 无承接
- 无新主链
- 忌进入兑现层
- 双忌持续
- 高压权结构
- 空劫并行
- 低能级且无外援

则：

收缩会形成：

- 崩塌
- 失控
- 漏穿
- 现实断裂

---

#### 第二类：触底重组 / 触底反弹

若同时满足：

- 有新主链形成
- 有禄接力
- 有科显化修正
- 权是推动而非压制
- 原系统本就错误
- 忌正在去泡沫
- 忌正在强制纠偏
- 忌正在断旧立新

则：

忌会形成：

- 去旧结构
- 强制转向
- 被迫重建
- 极限压缩后的重新兑现

注意：

这不是“忌变吉”。

而是：

旧结构收缩后，
形成了新的现实结构。

---

### 5.2 禁止错误映射

禁止：

- 忌一定坏
- 落陷忌一定崩
- 化忌一定失败
- 低亮度一定无救

因为：

低亮度 + 忌，

有时恰恰代表：

旧结构已经撑不住，
必须被迫重组。

尤其：

- 破军
- 七杀
- 贪狼
- 廉贞
- 巨门

等带有：

- 破旧
- 重构
- 转向
- 拆解
- 欲望变化
- 系统更新

属性的星曜。

落陷化忌时：

经常不是结束。

而是：

旧模式死亡。

---

### 5.3 忌的最终裁断原则

化忌最终必须检查：

#### 1）是否只是收缩

还是：

#### 2）已经形成现实断裂

以及：

#### 3）收缩后是否存在新承接结构

必须检查：

- 是否有新宫位接力
- 是否有禄科承接
- 是否有权推动重组
- 是否形成新主链
- 是否只是旧结构死亡

---

### 5.4 忌的最终铁律

忌代表系统收缩。

收缩后的结果：

可能是崩塌，
也可能是重组。

真正决定最终结果的：

不是“有没有忌”。

而是：

收缩后，
是否仍存在有效承接。

## 目标态根定义

⚠️ 四化：

只能描述：

> 星曜状态如何运动。

不能直接定义：

- 成功
- 失败
- 成立
- 不成立

因为：

任何事件：

都存在：

自身真正追求的：

> “目标态”。

而不同事件：

目标态可能完全不同。

---

### 一、目标态定义（核心）

所有事件：

最终都可以抽象为：

两种目标态：

---

#### 1）变化态

目标：

是：

- 持续变化
- 持续运动
- 持续扩张
- 持续流动
- 持续打开
- 持续推进

此时：

若出现：

- 停止运动
- 固化
- 冻结
- 封闭

则：

更容易形成：

- 阻断
- 停滞
- 推进中断。

---

#### 2）稳定态

目标：

是：

- 固定
- 稳定
- 锁定
- 不再变化
- 停止波动
- 进入确定状态

此时：

若出现：

- 停止运动
- 固化
- 冻结
- 封闭

反而可能意味着：

- 状态稳定
- 目标固定
- 结果收敛
- 进入最终态。

---

### 二、禁止错误读取（新增铁律）

禁止：

跳过：

“目标态判断”。

直接把：

- 忌
- 冻结
- 固化
- 停止运动

读取为：

- 失败
- 中断
- 不成立。

因为：

同一种：

“停止变化”。

在不同目标态中：

现实意义可能完全相反。

---

### 三、最终判断顺序（新增关键）

最终裁断时：

必须按以下顺序：

1）星曜本体
（现实物体是什么）

↓

2）四化动作
（该物体如何运动）

↓

3）目标态判断
（当前事件真正追求稳定还是变化）

↓

4）顺逆判断
（当前四化动作是顺目标还是逆目标）

↓

5）最终现实显像

禁止：

跳过：

“目标态判断”。

直接从：

四化动作

推导：

最终结果。

---

### 四、最终铁律（新增最高优先级）

⚠️ 四化：

永远只描述：

> “状态运动方式”。

真正决定：

该运动：

到底属于：

- 推进
  还是
- 阻断

的。

是：

当前事件的：

> 目标态。

不是：

四化本身。

## 四化链协议

### 总原则

#### 1. 四化链独立原则

四化分为：

- 禄链
- 权链
- 科链
- 忌链

每条链独立运行。

禁止跨链追四化。

---

#### 2. 追四化原则

链路类型决定追四化类型。

- 禄链 → 只追禄
- 权链 → 只追权
- 科链 → 只追科
- 忌链 → 只追忌

定义：

追四化=四化→来源宫

目的：

> 确定该四化的发源宫

---

#### 3. 推进器原则

所有链路统一使用：

推进器 = 忌

定义：

```text
当前节点宫
↓
取本宫宫干飞忌
↓
到达下一宫
```

注意：

> 忌只负责推进
> 不改变链路性质。

例如：

> 科链

推进过程中：

> 每一步都使用飞忌

但：

> 链路仍然属于科链

---

#### 4. 四化汇聚原则

定义:
四化汇聚:

> 宫位推进时，
> 可以汇集该链路类型的所有能量一起带入下个节点

比如:

> [主三宫]→天机科→P1宫
> P1宫内同时还有太阴星
> 因为太阴星可以化科，所以通过追四化[科]，找到P1_3宫

当宫位通过宫干飞忌进行推进时:
推进器会带着以下两个信息进入下个宫位:

> 1.[主三宫]→天机科→P1宫
> 2.p1_3宫→天阴科→P1宫

## 小星成本函数

### 小星本质

小星不是单纯的附加说明，而是作用在主星路径上的成本函数。

```text
小星 = 场域特性（Field） + 运行机制（Mechanism） + 代价函数（Cost）
```

| 维度     | 含义                         | 裁断用法                                         |
| :------- | :--------------------------- | :----------------------------------------------- |
| 场域特性 | 该宫位的气候、环境、背景色   | 判断此宫是稳定、混乱、隐性、过度、缺失还是噪音场 |
| 运行机制 | 能量在此如何运作             | 判断路径是卡、快、绕、断、漏、散、变还是被遮蔽   |
| 代价函数 | 完成同一结果要额外付出的成本 | 判断时间成本、路径成本、认知偏差成本、结构风险   |

对齐规则：

- 大星定框架。
- 小星定细节。
- 四化定变化与应期。
- 小星负责把“细节”升级为可计算的效率、摩擦和结构风险。

### 小星模型

裁断时，所有小星必须先归入至少一种类型。
同一小星可因宫位、组合、问题域而兼具多类，但输出时要说明主导类型。

| 类型                       | 关键词                             | 代表星曜                                   | 通用规则                                 | 成本表现         |
| :------------------------- | :--------------------------------- | :----------------------------------------- | :--------------------------------------- | :--------------- |
| 阻力型（Resistance）       | 卡、拖、反复、消耗、噪音、低频干扰 | 陀罗、擎羊、铃星、阴煞                     | 使路径产生摩擦、卡顿、延迟或难以直接推进 | 时间成本上升     |
| 流动型（Variation）        | 变化、切换、多路径、不稳定、移动   | 天马、天机类结构、右弼                     | 使路径产生多路径、不稳定、转向或持续变动 | 路径成本上升     |
| 染色型（Marker）           | 真假、情绪、标签、名相、隐性性质   | 天虚、天喜、病符、文曲忌、红鸾、咸池、天姚 | 改变结果性质，不优先改变路径结构         | 认知偏差成本上升 |
| 击穿型（Structural Break） | 断裂、崩塌、缺失、耗尽、结构改写   | 地劫、天空、大耗、截空、丧门               | 直接改变结构，不只是过程修饰             | 结构风险上升     |

补充归类：

| 星曜 | 默认类型         | 说明                                         |
| :--- | :--------------- | :------------------------------------------- |
| 地空 | 染色型 / 击穿型  | 轻则过度、多余、鼓起；重则空亡、结构空转     |
| 地劫 | 击穿型           | 本应有而没有，坑洞、断裂、缺口               |
| 火星 | 流动型 / 阻力型  | 速度、温度、光亮；过强时造成急躁、过热、灼伤 |
| 文昌 | 染色型 / 流动型  | 传播路径、偏斜、文书载体                     |
| 文曲 | 染色型           | 内容性质、文字数据、契约内容                 |
| 左辅 | 流动型           | 数量增加、多条路径、多层辅助                 |
| 右弼 | 流动型           | 转向、更新、再一次、路径改变                 |
| 禄存 | 击穿型 / 阻力型  | 块状堆积，可能形成堵塞或沉重成本             |
| 解神 | 击穿型的反向修复 | 分解、解除、终止旧结构                       |
| 天刑 | 阻力型 / 击穿型  | 规则切割、手术、惩罚、可控伤害               |

### 成本公式

```text
最终表现 = 四化方向 × 主星承载 × 落点宫位容器 × 小星修饰系数
```

其中：

```text
小星修饰系数 = 场域特性 + 运行机制 + 成本类型
```

裁断时不得只说“小星不好”。
必须说清楚它增加了哪一种成本。

### 小星+四化

#### 化禄：扩散与放大

```text
收益路径 = 化禄 ×（主星当前状态）×（1 - 阻力 + 变动 + 染色）
```

| 小星类型 | 对化禄的作用                                       |
| :------- | :------------------------------------------------- |
| 阻力型   | 收益变慢，资源进入但兑现延迟                       |
| 流动型   | 收益不稳定，资源路径多变或分散                     |
| 染色型   | 收益性质改变，可能变成情绪收益、名义收益、虚假收益 |
| 击穿型   | 放大缺口、空耗、断裂或结构性漏失                   |

示例：

- 太阴铃星化禄：储存的烦恼被放大，收益表现为“苦水增加”。
- 天机地劫化禄：运动空耗被放大，越动越白费力气。
- 贪狼地劫化禄：欲望被放大，但实际满足有缺口。

#### 化权：推进与施压

```text
推进路径 = 化权 ×（主星执行力）×（路径偏移 + 阻力 + 结构承压）
```

| 小星类型 | 对化权的作用                         |
| :------- | :----------------------------------- |
| 阻力型   | 推进卡顿，越推摩擦越大               |
| 流动型   | 推进方向变化，可能转向、换人、换路径 |
| 染色型   | 推进带有标签、情绪、名相或误判       |
| 击穿型   | 强制重构，可能直接改写结构           |

示例：

- 破军地劫化权：强行动作打到缺口上，突破可能变成结构重写或突破失败。
- 巨门地劫化权：强行打开通道，但通道本身有洞，易变成权限/沟通漏洞。

#### 化科：修正与缓冲

```text
修正路径 = 化科 ×（延迟 + 多轮修正 + 信息化）
```

| 小星类型 | 对化科的作用                         |
| :------- | :----------------------------------- |
| 阻力型   | 修正变慢，流程拖延                   |
| 流动型   | 反复修正，多次变更版本或路径         |
| 染色型   | 修正偏表面、名义、文书、标签化       |
| 击穿型   | 修正结构缺口，若承载不足则只留下补丁 |

示例：

- 巨门地劫化科：漏洞进入解释、修复、文书化流程，但速度慢。
- 文曲忌遇科：内容层面被修正，但容易停留在名相或文本表面。

#### 化忌：收缩与终止

```text
收缩路径 = 化忌 ×（当前状态终止）×（小星成本放大）
```

| 小星类型 | 对化忌的作用                   |
| :------- | :----------------------------- |
| 阻力型   | 问题拖长，终止过程不干脆       |
| 流动型   | 问题扩散，终止点移动或路径外溢 |
| 染色型   | 问题性质被误读，容易贴错标签   |
| 击穿型   | 直接崩塌、断裂、清空或结构终止 |

示例：

- 七杀地劫化忌：线性缺口被触发为断线节点，发展线中断。
- 天机陀罗化忌：运动/思维被反复缠住后终止，表现为卡住很久才停。

### 小星组合原则

任意小星组合都按场域叠加处理，不得只背固定组合。

```text
小星组合 = 场域叠加（Field Overlay）
最终场域 = ∑（各小星场域特性）
```

示例：

```text
流动型（天马） + 阻力型（陀罗）
= 变化中卡顿
= 多路径 + 摩擦
= 曲线推进结构
```

裁断输出：

> 该路径并非完全不能动，而是在变化中反复卡住，需要绕行、等待或多次调整。

### 成败裁断

```text
结果 = 四化方向（主导）
      × 主星能级（承载）
      × 落点宫位（容器）
      × 小星成本（效率/代价）
```

小星阻力不必然导致失败。
若满足以下条件，阻力可转化为筛选、优化、训练或防错机制：

```text
四化 ∈（化禄 / 化权 / 化科）
AND 主星能级 ≥ 平
AND 落点宫位可承载
AND 所问目标允许延迟、试错或多轮修正
```

转化规则：

| 小星成本     | 可转化为                       |
| :----------- | :----------------------------- |
| 时间成本     | 筛选机制、训练周期、沉淀过程   |
| 路径成本     | 多方案试错、路线优化、转向机会 |
| 认知偏差成本 | 标签校正、名义确认、信息澄清   |
| 结构风险     | 重构机会、止损点、旧结构清除   |

若不满足承载条件，小星成本会从“修饰”升级为“拖垮路径”的主导因素。

### 输出模板

裁断中必须使用以下句式之一：

```text
该路径在【宫位】中，受【小星类型】影响，
表现为【运行机制】，从而增加【成本类型】。
```

```text
该星曜原始成像为【主星图像】，
小星将其修饰为【细节图像】，
四化再使该图像进入【放大/推进/修正/终止】状态。
```

示例：

> 该路径在官禄宫中，受阻力型小星影响，表现为反复卡顿，从而增加时间成本。

> 天机原始成像为运动路径，陀罗将其修饰为绕圈与缠住，化忌再使该路径进入反复卡住后的终止状态。

### 禁止

- 禁止把某个小星固定为“坏”。
- 禁止把某个小星固定为“好”。
- 禁止把某个组合当作唯一结构，例如只认“天马 + 陀罗”。
- 禁止忽略小星类型分类直接下结论。
- 禁止只说“有阻碍”，必须说明阻碍属于时间成本、路径成本、认知偏差成本还是结构风险。
- 禁止小星越级覆盖主星；除非击穿型小星已经造成结构重写。

```text

```

存在。

因此：

```text
没有事件

没有应期
```

## 竞争协议

竞争类问题 = 相对兑现排序问题。

竞争结果 = 忌的击穿力 + 权的压迫力 + 科禄的剩余兑现力 + 群体同步强度 + 分层现实剩余承接状态。

该优先级 = 现实优先级。

该优先级 ≠ 固定吉凶排序。

禁止：

- 科多 = 前列
- 权强 = 高排名
- 禄多 = 优势
- 忌低 = 可以忽略
- 主体强 = 最终一定赢

竞争类最终必须区分：

- 绝对能力层
- 现实兑现层
- 相对排名层

+
