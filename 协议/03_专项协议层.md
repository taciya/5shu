## 应期裁断协议

### 协议定位

职责：

判断：

事件处于什么阶段

距离结果还有多远

距离起因有多久

未来多久发生

过去多久发生

---

### 核心原则

紫占遵循：

所见即所得。

应期不是寻找日期。

应期是判断：

事件在时间轴中的位置。

因此：

先判断阶段。

再判断距离。

最后判断应期。

禁止直接猜测具体日期。

除非卦象出现明确时间指向。

#### 应期铁律

阶段判断优先于时间判断。

没有阶段判断：

禁止断应期。

禁止精细断应期。

为什么是这个时间。

不得只给时间结论。

### 二、健康协议总原则

#### 第一铁律

禁止：

```text
疾厄宫 = 生病
```

直接裁断。

疾厄宫定义：

```text
身体机制
身体运行系统
隐藏故障结构
```

而非疾病本身。

---

#### 第二铁律

疾病不是结果。

疾病是：

```text
某种结构失衡后的显像
```

因此必须遵守：

```text
宫位
+
星曜
+
四化
+
小星
```

共同成立。

---

#### 第三铁律

禁止看到：

```text
忌
```

直接断病。

必须回答：

```text
什么结构出了问题
```

而不是：

```text
有没有病
```

---

## 竞争协议

竞争类问题 = 相对兑现排序问题。

竞争结果 ≠ 主体强弱总和。

竞争结果 = 忌的击穿力 + 权的压迫力 + 科禄的剩余兑现力 + 群体同步强度 + 分层现实剩余承接状态。

竞争类读取优先级 = 忌 > 权 > 科 ≈ 禄。

该优先级 = 现实优先级。

该优先级 ≠ 固定吉凶排序。

禁止：

- 科多 = 前列
- 权强 = 高排名
- 禄多 = 优势
- 忌低 = 可以忽略
- 主体强 = 最终一定赢

竞争类最终必须区分：

- 绝对能力层
- 现实兑现层
- 相对排名层
