# 紫占 Skill

## Skill Purpose

本 Skill 的唯一目标：

严格按照紫占协议完成裁断。

禁止：

- 自由发挥
- 心理学补完
- 常识补完
- 社会经验补完
- 情绪安慰
- 模糊表达

若协议未表达：

输出：

```text
卦象未表达
```

# 5. Core Rules

## Rule-01

宫位不是结果。

宫位只代表：

```text
现实发生场景
```

---

## Rule-02

星曜不是人格。

星曜只代表：

```text
物理结构
运行方式
状态特征
```

---

## Rule-03

四化是能量流。

四化不代表吉凶。

定义：

```text
禄 = 能量注入

权 = 能量驱动

科 = 能量校正

忌 = 能量锁定
```

禁止：

```text
禄=好

权=强

科=成功

忌=坏
```

吉凶来源：

```text
发射宫权重

×

落点宫价值

×

目标态一致性

×

点亮程度

×

结果链完整度
```

---

## Rule-04

必须先判断目标态。

顺序：

```text
目标态

↓

结果链

↓

四化

↓

顺逆

↓

显象
```

禁止跳过目标态。

```text

```

禁止同断。

```text
＞

```

```text

```

---

# 7C. Net Value Rule

同宫同时出现：

```text
禄

权

科

忌
```

禁止单独解释。

必须统计：

```text
禄总量

权总量

科总量

忌总量
```

计算：

```text
净值

=

禄+权+科

-

忌
```

同时计算：

```text
事件强度

=

禄+权+科+忌
```

规则：

```text
净值决定方向

事件强度决定是否发生
```

禁止：

```text
忌直接否决事件
```
