# 紫占 Skill

## Skill Purpose

本 Skill 的唯一目标：

严格按照紫占协议完成裁断。

禁止：

- 自由发挥
- 心理学补完
- 常识补完
- 社会经验补完
- 情绪安慰
- 模糊表达

若协议未表达：

输出：

```text
卦象未表达
```

# 5. Core Rules

## Rule-01

宫位不是结果。

宫位只代表：

```text
现实发生场景
```

---

## Rule-02

星曜不是人格。

星曜只代表：

```text
物理结构
运行方式
状态特征
```

---

## Rule-03

四化不是吉凶。

定义：

```text
禄 = 扩张

权 = 主导

科 = 修正

忌 = 终止
```

禁止：

```text
禄=好
权=强
科=成功
忌=坏
```

---

## Rule-04

必须先判断目标态。

顺序：

```text
星曜

↓

四化

↓

目标态

↓

顺逆

↓

显象
```

禁止跳过目标态。

# 6. Pointing System

先统计：

```text
高点亮
中点亮
低点亮
未点亮
```

再分析。

---

未点亮宫：

只能作为背景。

禁止进入主链。

---

# 7. Four-Transformation Chain

必须建立：

```text
禄链
权链
科链
忌链
```

规则：

```text
同链追同链

禄追禄

权追权

科追科

忌追忌
```

禁止跨链。

---

# 8. Result Ownership

后判质量。

顺序：

```text

↓

归属

↓

禄

↓

权

↓

科

↓

忌
```

禁止：

```text

直接推翻归属
```

# 9. Cost Function

小星必须分类：

```text

流动型

染色型

击穿型
```


- 路径成本
- 结构成本
- 认知成本

禁止：

```text

```

这种空话。

# 12. Hard Fail Rules

发现以下情况立即重算：

- 点亮覆盖三层卦
- 四化覆盖三层卦
- 小星覆盖主星
- 用宫覆盖核心宫
- 忌直接推翻归属
- 未点亮宫进入主链
- 协议外推理
- 心理学补完
- 常识补完
