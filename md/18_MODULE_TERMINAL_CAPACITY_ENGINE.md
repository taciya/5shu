# MODULE_TERMINAL_CAPACITY_ENGINE

## 一、核心定义

⚠️ 去向宫 ≠ 一定能承载结果。

必须检测：

该宫位是否真正有能力承接飞入结果

---

## 二、承载检测总公式

承载能力=
宫位稳定度

- 主星承载度
- 四化支持度

* 小星破坏度

  ---

## 三、承载等级

| 等级              | 定义                 |
| ----------------- | -------------------- |
| stable_terminal   | 具备长期承载能力     |
| weak_terminal     | 存在长期衰减风险     |
| overload_terminal | 当前负载超过结构上限 |
| collapse_terminal | 结构无法继续承载     |
