## 0.2 四化根定义

禄 = 聚集 + 扩张 + 储存 + 持续 + 增殖 + 累积。

权 = 强制推动 + 摩擦 + 控制测试 + 主导争夺 + 规则压迫。

科 = 显化 + 被看见 + 传播 + 表达 + 可见化 + 名义化。

忌 = 阻断 + 漏损 + 扭曲 + 侵蚀 + 消耗 + 断裂 + 失控。

四化 = 现实动力方向。

四化 ≠ 吉凶评分系统。

四化 ≠ 加减分系统。

四化 ≠ 排名分系统。

四化 ≠ 固定好坏标签。

---

读取四化时，禁止自动联想：

- 禄 = 吉利
- 禄 = 一定有利

## 0.5 星曜根定义层

星曜 = 物理载体模型。

星曜 ≠ 独立吉凶标签。

星曜必须先定义其原始物理形态，再接受四化改变。

读取顺序 = 星曜原始模型 -> 宫位场景 -> 能级状态 -> 四化动作 -> 现实显像。

禁止脱离星曜原始模型直接用四化下结论。

---

## 0.6 宫位根定义层

宫位 = 事件发生的现实场景容器。

宫位 ≠ 结果本身。

命宫 = 主体、自身状态、第一视角。

财帛宫 = 资源流、现金流、交易、可动用资源、兑现层。

官禄宫 = 职业路径、项目运行、制度目标、规则层。

子女宫 = 产出、作品、发挥层、结果承接层。

父母宫 = 权威、证件、文书、单位、规则、上级、制度接口。

迁移宫 = 外部环境、不可控因素、远方、外界变量。

福德宫 = 想法、心念、精神感受、内在享受。

疾厄宫 = 身体机制、隐性结构、内部故障。

田宅宫 = 空间、房产、存放处、家族底盘、资产容器。

夫妻宫 = 契约关系、绑定关系、合作对象。

兄弟宫 = 同属性不同体、平辈、同类、同行、横向关系。

交友/仆役宫 = 外部协作对象、客户、朋友、团队接口。

---

## 0.7 能级根定义层

能级 = 显像强度与现实穿透力。

能级 ≠ 吉凶分数。

高能级 = 更容易显化、更难忽略、更能压制低能级结构。

低能级 = 显像弱、物理化慢、受干扰多。

低能级 ≠ 无效。

若低能级作用于关键宫位、关键星曜、关键四化或高权重现实中断层：

仍必须进入主线分析。

---

## 0.8 竞争类根定义层

竞争类问题 = 相对兑现排序问题。

竞争结果 ≠ 主体强弱总和。

竞争结果 = 忌的击穿力 + 权的压迫力 + 科禄的剩余兑现力 + 群体同步强度 + 现实承接状态。

竞争类读取优先级 = 忌 > 权 > 科 ≈ 禄。

该优先级 = 现实优先级。

该优先级 ≠ 固定吉凶排序。

禁止：

- 科多 = 前列
- 权强 = 高排名
- 禄多 = 优势
- 忌低 = 可以忽略
- 主体强 = 最终一定赢

竞争类最终必须区分：

- 绝对能力层
- 现实兑现层
- 相对排名层

---

## 0.9 奇门根定义层

奇门 = 现实运行场观察层。

奇门 ≠ 因果系统。

奇门 ≠ 事件成立系统。

奇门 ≠ 紫占飞四化的替代物。

飞四化 = 唯一合法因果层。

奇门 = 因果进入现实后的场域开合、通道通畅、执行真假、空间阻塞观察层。

禁止用奇门：

- 替代飞四化
- 推翻飞四化
- 修改发源宫
- 修改去向宫
- 单独定成败
- 单独定吉凶

## 星曜亮度使用总规则

星曜亮度：

属于：

> 星曜现实承载能力。

亮度只负责：

- 兑现稳定度
- 承载上限
- 波动风险
- 是否容易被忌击穿

禁止：

将亮度直接转换为：

- 数值倍率
- 百分比加成
- 固定增幅

例如：

以下全部禁止：

- 庙 ×1.2
- 旺 ×1.1
- 陷 ×0.7
- 利 +15%

亮度：

只能参与：

现实兑现收敛。

不得：

直接修改：

四化原始百分比。

## 冲突处理原则

### 五术成立，但奇门阻塞

若奇门显示：

- 杜门
- 死门
- 惊门
- 景门失真
- 空亡
- 马星受阻
- 假推进
- Flow State 崩塌

则：

只能修正：

- 推进难度
- 落地效率
- 推进速度
- 阻力大小
- 信息真实性
- 是否反复
- 是否空转
- 是否延迟

不得：

否定五术成立。

---

- 开门

生成：

- 不存在的事件
- 不存在的关系
- 不存在的结果

运行环境具备推进条件。
