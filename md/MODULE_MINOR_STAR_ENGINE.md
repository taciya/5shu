## 十三、小星+四化理则

---

### 13.1 小星三层本质定义

```text
小星 = 场域特性（Field） + 运行机制（Mechanism） + 代价函数（Cost）
```

---

#### 💎 拆解：

| 维度   | 含义                     |
| ---- | ---------------------- |
| 场域特性 | 该宫位“气候/环境”（如：混乱、稳定、隐性） |
| 运行机制 | 能量在此如何运作（卡、快、绕、断）      |
| 代价函数 | 完成同一结果需要付出的成本          |

---

👉 对齐原协议：

* ✔ 对应「小星染色」
* ✔ 对应「摩擦级/击穿级/标记级」
* ✔ 但升级为**可计算模型**


---

### 13.2 三大通用类型（强制分类）

---

#### 🧱 ① 阻力型（Resistance）

👉 关键词：卡、拖、反复、消耗

| 星类         | 示例 |
| ---------- | -- |
| 陀罗、擎羊、铃星   |    |
| 阴煞（低频持续干扰） |    |

---

👉 通用规则：

```text
使路径产生“摩擦/卡顿/延迟”
```

---

---

#### 🌊 ② 流动型（Variation）

👉 关键词：变化、切换、多路径

| 星类       | 示例 |
| -------- | -- |
| 天马、天机类结构 |    |

---

👉 通用规则：

```text
使路径产生“多路径/不稳定/变动”
```

---

---

#### 🧬 ③ 染色型（Marker）

👉 关键词：真假、情绪、隐性标签

| 星类           | 示例 |
| ------------ | -- |
| 天虚、天喜、病符、文曲忌 |    |

---

👉 通用规则：

```text
改变结果“性质”，不改变路径结构
```

---

---

#### 💥 ④ 击穿型（Structural Break）

👉 关键词：断裂、崩塌

| 星类       | 示例 |
| -------- | -- |
| 地劫、天空、大耗 |    |

---

👉 通用规则：

```text
直接改变结构（非过程修饰，而是结构重写）
```

---

### 13.3 通用计算逻辑

```text
最终表现 = 四化方向 × 主星承载 × 小星修饰系数
```

---

### 13.4 小星作用方式（统一公式）

---

#### 🟢 对禄（扩散）

```text
收益路径 = 禄 ×（1 - 阻力 + 变动）
```

👉 结果：

* 阻力型 → 收益变慢
* 流动型 → 收益不稳定
* 染色型 → 收益性质改变

---

---

#### 🔵 对权（推进）

```text
推进路径 = 权 ×（路径偏移 + 阻力）
```

👉 结果：

* 阻力型 → 推进卡顿
* 流动型 → 推进方向变化
* 击穿型 → 强制重构

---

---

#### 🟡 对科（修正）

```text
修正路径 = 科 ×（延迟 + 多轮修正）
```

👉 结果：

* 阻力型 → 修正变慢
* 流动型 → 反复修正
* 染色型 → 修正偏表面

---

---

#### 🔴 对忌（收缩）

```text
收缩路径 = 忌 ×（放大系数 × 小星）
```

👉 结果：

* 阻力型 → 问题拖长
* 流动型 → 问题扩散
* 击穿型 → 直接崩塌

---

### 13.5 小星组合通用规则（核心）

---

#### 🎯 任意组合：

```text
小星组合 = 场域叠加（Field Overlay）
```

---

#### 📌 运算方式：

```text
最终场域 = ∑（各小星场域特性）
```

---

---

#### 🎯 示例（替代原天马+陀罗）

```text
流动型（天马） + 阻力型（陀罗）
= “变化中卡顿”
```

👉 抽象为：

```text
多路径 + 摩擦 = 曲线推进结构
```

---

👉 不再写死某对星，而是：

👉 **任何组合都可计算**

---

### 13.6 成败判定（修订版）

---

```text
结果 = 四化方向（主导）
      × 主星能级（承载）
      × 落点宫位（容器）
      × 小星成本（效率/代价）
```

---

### ❗关键变化：

👉 小星从“附加说明”
👉 升级为：

👉 **“成本函数”**

---

---

### 13.7 成本判定规则

| 小星类型 | 成本表现     |
| ---- | -------- |
| 阻力型  | 时间成本 ↑   |
| 流动型  | 路径成本 ↑   |
| 染色型  | 认知偏差成本 ↑ |
| 击穿型  | 结构风险 ↑   |

---

### 13.8 成立条件（通用）

```text
若：
四化 ∈（禄/权/科）
AND 主星能级 ≥ 平
AND 落点宫可承载
```

---

### 🎯 则：

```text
小星阻力 → 转化为：
筛选机制 / 优化机制 / 训练机制
```

---

👉 对齐你原规则，但升级为：

👉 **适用于所有小星**

---

### 13.9 小星表达模板（必须用）

---

```text
“该路径在此宫位，受（小星类型）影响，
表现为（运行机制），从而增加（成本类型）”
```

---

#### 📌 示例（通用）

👉
“该路径在官禄宫，受阻力型小星影响，表现为反复卡顿，从而增加时间成本”

---

### 13.10 禁止错误（补充）

❌ 把某个小星固定为“坏”
❌ 把某个组合当作唯一结构（如只认天马陀罗）
❌ 忽略小星类型分类直接下结论

---

### 13.11 新增执行补丁
执行顺序：

1. 小星分类（强制）：
   - 阻力型
   - 流动型
   - 染色型
   - 击穿型

2. 成本计算：
   成本类型：
   - 时间成本
   - 路径成本
   - 认知成本
   - 结构成本

3. 强制输出：
“该路径在XX宫位，
受XX类型小星影响，
表现为XX机制，
从而增加XX成本”
