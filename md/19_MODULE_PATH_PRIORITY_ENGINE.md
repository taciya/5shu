### 2.1｜Path Heat（新增）

#### 核心定义

Path Heat：

代表：

当前路径的现实活跃度。

用于：

区分：

“背景旧路径”
与
“真正正在发生的主路径”

---

#### Path Heat公式

path_heat =
能级
×
动态激活等级
×
重复承接次数
×
现实反馈强度
×
最近触发度

---

#### 热度等级

| 等级      | 定义           |
| --------- | -------------- |
| ultra_hot | 当前主现实路径 |
| hot       | 高频活跃路径   |
| warm      | 持续背景路径   |
| cold      | 低活跃路径     |
| frozen    | 已失活路径     |

---

#### ultra_hot 条件

满足任一：

- 三层共振宫
- 一级动态激活宫
- 高能忌路径
- collapse_structure
- Terminal最终落点

---

#### frozen 条件

满足：

- 能级 ≤15%
- 无继续承接
- 无现实反馈
- 无动态激活

---

#### 最终协议

⚠️ Path Priority：

必须优先参考：

Path Heat。

禁止：

低热度旧路径
覆盖
高热度当前路径。
