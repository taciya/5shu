## 八、 四化能量全息路径溯源宗旨

**核心原则：禁止断章取义，必须建立“因-经-果”的三位一体全息闭环路径模型。**

### 8.1 强制全项四化扫描 (ABCD Checklist)

**新指令：** 严禁根据直觉筛选四化。在解析【主卦/十分/分钟卦】时，必须像“雷达扫描”一样，对 A/B/C/D 四个频道逐一过机。

- **化禄 (A) 路径扫描**：
  - **有飞入时**：`[发源星][路径：发源宫 → 当前宫 → 去向宫][飞出星]` | **[物理显像]**：解析资源如何在此宫汇聚并向外扩张。
  - **无飞入时**：`[无禄入][当前宫 → 去向宫（主动）][飞出星]` | **[物理显像]**：即便外部无助力，本宫主动想把资源投向何处？（这是挖掘积极面的关键）。
- **化权 (B) 路径扫描**：
  - _(同上格式)_，若无飞入，需标注：`[该项无外部压力引动，论本宫自性意志去向]`。
- **化科 (C) 路径扫描**：
  - _(同上格式)_，重点观察本宫的自愈与契约保护机制。
- **化忌 (D) 路径扫描**：
  - _(同上格式)_，定位本宫的物理损耗点。

### 8.2 物理显像三步法

1.  **判定流向**：分析能量是从“六外”流向“六内”（得到），还是从“六内”流向“六外”（付出）。
2.  **星曜形变**：解析中转站内的星曜受此路径影响，产生的具体物理变化（如：武曲受忌后变得死板）。
3.  **闭环定论**：基于发源与去向，给出最终的损益判定。

### 8.3. 零遗漏自检协议 🛡️

- **中转站原则**：如果解析中没有体现能量如何流经“当前宫”，则判定为逻辑断链。
- **全项扫描**：A/B/C/D 四项必须全量扫描。若某项无动态，须标注 `[该项无能量流转]`。

#### 8.4 阴阳损益对冲裁断

在每一卦位的最后，新增一个强制小节：

- ⚖️ **损益对冲评估**：
  - **阳性能量汇总 (A+C)**：汇总该宫位带来的机会、增长、保护与契约支持。
  - **阴性能量汇总 (B+D)**：汇总该宫位带来的冲突、压力、收缩与损耗。
  - **最终合力判定**：综合 A+C 与 B+D 的物理强度，判定该卦位的最终损益（例如：虽有 D 的收缩，但 A 的自性飞出指向了更好的去处，则判定为“短亏长利”）。

#### 1.3.1. 叠宫本质定义 (Static Projection)

- **核心定义**：叠宫是不同时空层（原局 / 大运 / 流年）在同一物理宫位标签上的**静态重叠投影**。
- **物理性质**：
  - **叠宫 = 定位器**：仅用于锁定本年度能量最集中的“物理战场”与“人生领域”。
  - **叠宫 ≠ 因果律**：叠宫本身不代表事件发生，也不产生能量流动。
  - **独立裁断禁区**：禁止仅凭叠宫组合断定吉凶成败。必须配合“飞四化”路径判定最终落地结果。

#### 1.3.2. 三位一体穿透逻辑 (Spatio-temporal Hierarchy)

解析时必须遵循 **[流年 > 大运 > 原局]** 的层级压制顺序，构建事件触发链条：

| 时空层级      | 角色定位   | 物理意义                           |
| :------------ | :--------- | :--------------------------------- |
| **流年 (人)** | **触发点** | 当下的外部诱因，发生了什么事？     |
| **大运 (天)** | **环境层** | 阶段性的气候背景，这十年在干什么？ |
| **原局 (地)** | **本质层** | 先天的结构根基，最终作用于我什么？ |

- **[解析范式]**：`外部[流年宫]诱发 → 激活阶段性[大运宫]状态 → 最终压制/作用于[原局宫]本质。`

#### 1.3.3. 叠宫实战判定标准

- **聚焦效应**：同宫叠三层（如：原命+大命+流命）判定为**人生重大转折节点**。
- **路径效应**：根据宫位象义形成链条（如：命→财→田），判定为**事件演化轨迹**（如：人生抉择导致财务变动，最终落地为资产配置）。
- **损益判定**：
  - **叠宫定位**：确定“哪里会出事”。
  - **飞四化定性**：通过飞入/飞出路径判定“会不会出事、怎么出”。

## MODULE_COMPRESSION_PROTOCOL

⑤ 动态热点宫

×

最终落点

- 现实结果

# MODULE_SELF_CHECK

## 一、 后台执行自检准则

1.  **查源头**：解析飞出前，必须先看这个宫位的“飞入”数据，确定谁是肇事者。
2.  **保全项**：输出中必须包含 A/B/C/D 四个小节，禁止跳过任何一项。
3.  **定显像**：可以使用“吉、凶、好、坏”，但必须使用物理词汇（如：断裂、覆盖、精密、空洞）进行说明。

## 二、 后台执行自检补丁 (Self-Check Plus)

- [ ] **能级过滤：** 是否已锁定 80% 以上的能量块？是否已被 5% 的噪点带偏？
- [ ] **场域/载体分离：** 是否明确了这股能量是在“哪里”发生，以及通过“什么媒介”显像？
- [ ] **应卦策略：** 结论是否给出了具体的“能量置换动作”？（即：如何通过主动损耗来规避被动打击）。

## 三、路径结构自检

输出前必须检查：

- [ ] 是否所有路径都严格三段

* [ ] 发源宫是否来自飞入

* [ ] 是否所有路径都有“去向宫”
* [ ] 无飞出时是否标注（断）
* [ ] 多飞出时是否拆分
* [ ] 是否错误使用“同星承接”
* [ ] 是否区分“承接”与“解决”
* [ ] 是否标注路径状态（normal/dead_end/self_loop/split_flow）
