# ===== MODULE_PATH_ENGINE_APPEND_V3 =====

## 九、路径承接与断路径协议（新增最高优先级）

### 9.1 三段路径强制协议（新增硬规则）

所有路径必须统一表达为：

```text
【发源宫】 → 【当前宫】 → 【去向宫】
```

禁止：

❌ 两段路径
❌ 用“停在这里”代替去向
❌ 省略去向宫

---

### 9.2 路径承接定义（新增）

#### 【承接成立条件】

👉 当前宫存在“飞出四化到其他宫位”

则判定：

```text
该路径存在承接
```

⚠️ 注意：

* 不要求“同星”
* 不要求“四化类型一致”
* 只要求：
  当前宫存在继续外流

---

#### 【承接本质】

```text
承接 = 能量继续流动
```

不是：

❌ 星曜相同
❌ 四化相同

---

### 9.3 断路径定义（新增）

若：

* 当前宫无飞出
  或
* 仅存在自循环（飞回本宫）

则判定：

```text
断路径（dead_end）
```

---

### 9.4 断路径强制表达（新增）

若为断路径：

必须写成：

```text
发源宫 → 当前宫 → 当前宫（断）
```

示例：

```text
命宫 → 夫妻宫 → 夫妻宫（断）
```

并必须注明：

```text
该能量停滞于当前宫，未继续外流
```

---

### 9.5 分流路径协议（新增）

若当前宫存在多个飞出：

必须：

👉 每一个飞出单独拆成一条路径

禁止：

❌ 合并多飞出
❌ 用一句话概括多个结果

---

#### 示例（正确）

```text
命宫 → 夫妻宫 → 兄弟宫
命宫 → 夫妻宫 → 命宫
命宫 → 夫妻宫 → 疾厄宫
```

---

### 9.6 自循环路径定义（新增）

若：

```text
当前宫飞出 → 当前宫
```

则判定：

```text
自循环路径（self_loop）
```

---

#### 自循环物理定义：

```text
能量未离开当前场域，
表现为：
反复、内耗、自我强化、持续循环
```

---

### 9.7 路径状态分类（新增）

所有路径必须标记：

| 类型         | 定义     |
| ---------- | ------ |
| normal     | 正常流动路径 |
| dead_end   | 断路径    |
| self_loop  | 自循环    |
| split_flow | 分流路径   |

---

### 9.8 承接 ≠ 解决（新增关键规则）

⚠️ 必须明确：

```text
路径继续 ≠ 问题解决
```

必须继续判断：

* 飞出去向
* 飞出星曜性质
* 最终是否：
  收敛 / 转移 / 扩散 / 击穿

---

#### 示例：

```text
太阴忌进入夫妻宫，
虽继续飞出至兄弟宫，
但若飞出为贪狼忌，
则问题只是转移为消耗，
并未真正收敛。
```

---

### 9.9 路径分析顺序（新增）

所有路径必须按以下顺序解析：

```text
① 是否有承接
→ ② 承接到哪里
→ ③ 承接后变成什么
→ ④ 是否真正收敛
```

---

### 9.10 路径完整性最终铁律（新增）

```text
路径是否成立：
只看有没有飞出

问题是否解决：
才看飞出的是什么
```

## 十五、路径结构自检（新增强制）

输出前必须检查：

* [ ] 是否所有路径都严格三段
* [ ] 是否存在两段路径
* [ ] 是否所有路径都有“去向宫”
* [ ] 无飞出时是否标注（断）
* [ ] 多飞出时是否拆分
* [ ] 是否错误使用“同星承接”
* [ ] 是否区分“承接”与“解决”
* [ ] 是否标注路径状态（normal/dead_end/self_loop/split_flow）

👉 任一失败：

```text
判定：
路径结构错误 → 必须重算
```
