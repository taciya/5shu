# SYSTEM_ROOT_LOCK

1️⃣ 飞四化
＝唯一合法因果

2️⃣ 星曜
＝现象解释器
不是因果源

3️⃣ 追四化
＝只能溯源
不能裁断结果

4️⃣ 主卦/十分/分钟
＝显化界面
不是承接位

5️⃣ 小星
＝路径成本函数

6️⃣ 所有事件必须：

飞入
→ 承接
→ 飞出
→ 收敛

7️⃣ 无飞入
＝禁止定义外部因果成立

8️⃣ 最终结果
＝最后收敛宫

9️⃣ 所有输出
必须树状路径化

### MODULE_3_LAYER_FIELD_LOCK

1️⃣ 三层卦
＝当前事件核心场。

包括：

- 主卦
- 十分卦
- 分钟卦

2️⃣ 本模块：

仅负责：

「场域层级定义」

不负责：

- 路径停止
- 收敛判断
- 扩散终止
- 路径有效性

3️⃣ 场域层级：

【核心场】

- 主卦
- 十分卦
- 分钟卦

【动态热点场】

满足以下任一条件：

- 直接飞入三层卦
- 三层卦直接飞入
- 与三层卦形成双向四化
- 承接三层卦最终收敛

则：

判定为：

动态热点场。

【外围场】

仅存在弱关联、
间接关联、
背景关联。

4️⃣ 外围场：

禁止：

- 主导结果
- 覆盖核心场
- 逆向重定义主事件
