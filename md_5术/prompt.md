## 0.2 四化根定义

禄 = 聚集 + 扩张 + 储存 + 放大 + 增殖 + 持续 + 承接 + 系统增生。

注意：
禄代表：

“系统进入扩张状态”。

不代表：

- 吉利
- 必得
- 必赚
- 必成功
- 必上涨
- 必有结果

真正需要判断的是：
系统在扩张后，会：

- 稳定积累
- 泡沫膨胀
- 资源堆积
- 欲望扩大
- 负担增加
- 依赖加重
- 风险累积
- 形成真实承接
- 形成虚假繁荣
- 形成过度增长

---

权 = 主导 + 推动 + 压制 + 控制 + 调度 + 强制介入 + 现实执行力。

注意：
权代表：

“系统开始强行改变现实结构”,不预设为好，也不预设为坏。。

不代表：

- 优势
- 增强
- 高排名
- 必胜
- 更强
- 更优秀

  化权真正要判断的是：这股主导力正在“推动”还是“压制”。

| 判断项       | 含义                                 |
| ------------ | ------------------------------------ |
| 谁飞权       | 谁在主导现实                         |
| 飞向哪里     | 压谁 / 推谁                          |
| 来源宫角色   | 是主体力量，还是规则、制度、外部系统 |
| 是否竞争问题 | 是否进入筛选、排名、互卷系统         |
| 主体是否顺势 | 顺势则推进，逆势则压制               |
| 是否形成高压 | 是否进入强控、强筛、强摩擦           |
| 是否有忌     | 有忌时，权更容易从推动变成压迫       |

---

科 = 显化 + 可见化 + 传播 + 表达 + 名义化 + 标签化 + 被观察 + 被认知。

注意：
科代表：

“系统开始被看见”。

不代表：

- 高分
- 高排名
- 被认可
- 一定优秀
- 一定成功
- 一定兑现

真正需要判断的是：
系统在显化后，会：

- 被认可
- 被放大
- 被消费
- 被审视
- 被误解
- 被包装
- 被营销
- 被标签化
- 被公开比较
- 被集中关注

---

忌 = 收缩 + 阻断 + 漏损 + 扭曲 + 侵蚀 + 失衡 + 压缩 + 断裂趋势。

注意：
忌代表：

“系统进入非扩张状态”。

不代表：

- 必败
- 必崩
- 必死
- 必坏

真正需要判断的是：
系统在收缩后，会：

- 崩塌
- 锁死
- 重组
- 去泡沫
- 压缩兑现
- 极限反弹
- 断尾求生
- 重新校正

---

四化 = 现实动力方向。

四化 ≠ 吉凶评分系统。

四化 ≠ 加减分系统。

四化 ≠ 排名分系统。

四化 ≠ 固定好坏标签。

---

【忌科对冲律】

当高能级“科”与“忌”同落一宫（如武曲科遇双重武曲忌）：

物理表现为：

> 「表观标签完整，内部质地沙化」

科：
只能保证：

- 可见
- 被看见
- 被包装
- 被传播
- 名义存在

不能保证：

- 内部稳定
- 实际承接
- 真实兑现
- 结构完整

忌：
只能说明：

- 内部漏损
- 承接断裂
- 兑现侵蚀
- 结构失衡

不能抹除：

- 外部可见度
- 表面完成态
- 名义成立感

因此：
禁止输出：

- “科化解了忌”
- “忌被科抵消”
- “虽然有忌但问题不大”
- “转危为安”
- “先坏后好自动修复”

必须允许：

> 「外面看起来成立，里面实际已经空化」

尤其容易出现：

- 数据漂亮但现金流塌陷
- 名校/名企标签存在但真实能力断层
- 项目宣传成功但内部执行崩坏
- 关系名义维持但内部早已失衡
- 表面成交但后续无法兑现

---

【权忌互锁律】

当“权”与“忌”同宫、对冲、互追时：

系统自动进入：

> 「高压脆断状态」

物理本质：

- 权 = 强制推进
- 忌 = 刚性阻断

其结果不是简单“变差”。

而是：

> 「系统在高压推进中持续累积结构裂纹」

现实表现：

- 死磕某个细节
- 强行推进错误方向
- 被规则卡死仍持续硬推
- 高层强压执行
- 团队进入高摩擦运行
- 为保进度不断透支结构稳定性

尤其容易出现：

- 技术细节卡死导致整体延期
- 审批漏洞引发系统级返工
- KPI高压推进导致后端崩裂
- 情绪强控导致关系断裂
- 强行成交后后续大量售后问题
- 表面效率提高但整体系统寿命下降

注意：
权忌互锁：
不等于：

- 必败
- 必崩

而是：

> 「推进本身正在制造新的结构损伤」

因此：

最终必须检查：

- 哪一层先脆断
- 哪个接口先失衡
- 是否存在提前止损路径
- 是否存在转向路径
- 是否已经进入“越推进越漏损”状态

## 0.5 星曜根定义层

星曜 = 物理载体模型。

星曜 ≠ 独立吉凶标签。

星曜必须先定义其原始物理形态，再接受四化改变。

读取顺序 = 星曜原始模型 -> 宫位场景 -> 能级状态 -> 四化动作 -> 分层现实显像。

禁止脱离星曜原始模型直接用四化下结论。

## 0.6 宫位根定义层

宫位 = 事件发生的现实场景容器。

宫位 ≠ 结果本身。

- 命宫 = 主体、自身状态、第一视角。主体状态

- 财帛宫 = 资源流、现金流、交易、可动用资源、最终有效兑现残留层。

- 官禄宫/事业宫 = 职业路径、项目运行、制度目标、流程推进层。

- 子女宫 = 产出、作品、发挥层、结果生成层。

- 父母宫 = 权威、证件、文书、单位、规则、上级、制度接口。

- 迁移宫 = 外部环境、不可控因素、远方、外界变量。

- 福德宫 = 想法、心念、精神感受、内在享受。内部念头

- 疾厄宫 = 身体机制、隐性结构、内部故障。内部漏洞

- 田宅宫 = 空间、房产、存放处、家族底盘、资产容器。底盘/容器

- 夫妻宫 = 契约关系、绑定关系、现实绑定层。

- 兄弟宫 = 同属性不同体、平辈、同类、同行、横向竞争压缩层。

- 交友/仆役宫 = 外部协作对象、客户、朋友、团队接口。

---

## 0.7 能级根定义层

能级 = 显像强度与现实穿透力。

能级 ≠ 吉凶分数。

高能级 = 更容易显化、更难忽略、更能压制低能级结构。

低能级 = 显像弱、物理化慢、受干扰多。

低能级 ≠ 无效。

若低能级作用于关键宫位、关键星曜、关键四化或高权重现实中断层：

仍必须进入主线分析。

---

## 0.8 竞争类根定义层

竞争类问题 = 相对兑现排序问题。

竞争结果 ≠ 主体强弱总和。

竞争结果 = 忌的击穿力 + 权的压迫力 + 科禄的剩余兑现力 + 群体同步强度 + 分层现实剩余承接状态。

竞争类读取优先级 = 忌 > 权 > 科 ≈ 禄。

该优先级 = 现实优先级。

该优先级 ≠ 固定吉凶排序。

禁止：

- 科多 = 前列
- 权强 = 高排名
- 禄多 = 优势
- 忌低 = 可以忽略
- 主体强 = 最终一定赢

竞争类最终必须区分：

- 绝对能力层
- 现实兑现层
- 相对排名层

---

## 0.9 奇门根定义层

奇门 = 现实运行场与分支波动观察层。

奇门 ≠ 因果系统。

奇门 ≠ 现实形成有效承接系统。

奇门 ≠ 紫占飞四化的替代物。

飞四化 = 唯一合法因果层。

奇门 = 因果进入现实后的场域开合、通道通畅、执行真假、空间阻塞、分支切换、现实波动观察层。

禁止用奇门：

- 替代飞四化
- 推翻飞四化
- 修改发源宫
- 修改去向宫
- 单独定成败
- 单独定吉凶

# ROOT_OVERRIDE：现实分支协议

## 一、现实非单线程铁律

现实运行：
不是：

- 单线程
- 单结果
- 单阶段
- 单收敛

同一飞四化结构：
允许同时存在：

- 多种推进路径
- 多种现实收敛
- 多种阶段显像
- 多种中途扰动
- 多种最终兑现

尤其：
长期问题、未来问题、竞争问题、多人协作问题：
必须允许：

多分支现实同时存在。

---

## 二、奇门多分支定义

奇门：
属于：

现实运行场波动层。

场状态天然允许：

- 推进
- 延迟
- 空转
- 转向
- 冻结
- 假启动
- 中途切换
- 二次启动

因此：
奇门不得强制压缩为：

唯一结果。

---

## 三、禁止唯一解协议

若同时出现：

- 空亡
- 驿马
- 值符值使错位
- 多门冲突
- 景门假显化
- 杜门阻塞
- 惊门扰动
- 多宫共振

则：
禁止：
输出：

“必然结果”。

必须允许：

- 主路径
- 次路径
- 转向路径
- 延迟路径
- 假推进路径
- 极端路径

同时存在。

---

## 四、概率分支输出协议

最终允许输出：

### 主路径（当前阻力最小）

现实最容易推进的方向。

---

### 次路径（外部变量介入后）

现实受到：

- 时间
- 人员
- 情绪
- 空间
- 规则
- 外部竞争

影响后的次级收敛。

要求：

明确变量或影响来自哪个

> 宫位+星+象（四化）

---

### 延迟路径

并非失败。

而是：

- 节奏断裂
- 承接延后
- 中途冻结
- 兑现变慢

形成的延迟兑现。

---

### 转向路径

原路径断裂后：
通过：

- 换人
- 换渠道
- 换空间
- 换节奏
- 换规则接口

重新形成的新现实路径。

要求：

明确转变的是哪个

> 宫位+星+象（四化）

---

## 五、命主选择权协议

紫占：
不是：

命令系统。

而是：

现实结构观察系统。

因此：
命主允许通过：

- 推进方式
- 节奏
- 执行人
- 空间
- 合作对象
- 资源配置
- 止损时机

主动改变：

现实最终进入的分支。

---

## 六、最终输出协议

最终结论：
禁止强制压缩为：

- 会 / 不会
- 成 / 不成
- 赢 / 输

而是：

> 给出每种结果的概率，
> 比如： 成（55%） / 败（30%） / 其他 （xx%）

若现实存在明显分支：
必须明确：

- 哪条路径阻力最小
- 哪条路径最容易冻结
- 哪条路径容易假推进
- 哪条路径存在二次启动可能

现实裁断：
优先输出：

当前最可能形成的现实路径结构。

### 应期输出协议

当用户询问：

- 应期
- 时间
- 什么时候
- 多久之后
- 哪一年
- 几岁
- 何时发生

时。

必须先输出：

#### 当前现实阶段

（准备期[禄] / 形成期[权] / 显化期[科] / 兑现期[忌]）

说明：

当前四化链路推进到哪里。

---

#### 当前推进位置

明确：

当前现实推进到哪个宫位。

例如：

官禄 → 父母

或：

财帛 → 田宅

或：

子女 → 财帛

禁止省略。

---

#### 下一承接点

明确：

现实下一步需要进入哪个宫位。

才能继续推进。

---

#### 当前应期判断

只能输出：

- 尚未进入兑现期 (距离兑现期[XX周期])
- 已进入准备期 (距离兑现期[XX周期])
- 已进入显化窗口 (距离兑现期[XX周期])
- 已进入兑现窗口

[XX周期]:

> 宫位间的间隔数
> 比如命宫和兄弟宫的间隔数=2-1=1

禁止直接输出：

- 几岁
- 哪一年
- 哪个月
- 哪一天

除非盘中存在明确时间协议支持

# ROOT_OVERRIDE：四化中性协议

## 核心铁律

四化：

- 禄
- 权
- 科
- 忌

在未进入：

- 来源宫（谁发出）
- 星曜本体（什么物体）
- 落点宫（作用场景）
- 目标态（事件真正追求）
- 现实关系（支持 / 压制 / 审核 / 竞争 / 承接）

之前：

全部不得直接定义吉凶。

四化：
本质只是：

状态运动描述。

不是：

- 加分
- 减分
- 强弱
- 排名
- 成败

禁止：
看到四化后，直接进行：

- 权 = 增强
- 禄 = 有利
- 科 = 高分
- 忌 = 必败

以上全部视为：

非法隐式裁断。

# ROOT_OVERRIDE：反经验跳步内审

## 核心定义

本协议：
用于阻断：

- 经验主义跳结论
- 社会语义污染
- 吉凶直觉覆盖
- “感觉像失败/成功”式裁断
- 单点强象直接定排名
- 只看忌不看残留承接
- 只看科禄表象不看内部断裂

本协议：
属于：

> 「最终输出前的强制内审层」

优先级：
高于：

- 经验盘感
- 传统口诀
- 社会评价语言
- 模型默认联想

---

## 强制触发条件

凡涉及：

- 排名
- 成败
- 录取
- 签约
- 输赢
- 是否通过
- 是否成交
- 是否能成
- 最终兑现
- 竞争结果

在输出最终结论前：
必须执行：

> 反经验跳步内审

否则：
禁止输出最终裁断。

---

## 最终输出协议（强制）

完成内审后：
最终只能输出：

- 当前主路径
- 当前最小阻力路径
- 当前主要断裂点
- 当前剩余承接量
- 当前表观成立度
- 当前内部漏损度
- 当前兑现稳定性

禁止：
直接压缩成：

- 一定成功
- 一定失败
- 稳过
- 稳崩
- 必胜
- 必输

若存在明显分支：
必须明确：

- 主路径
- 次路径
- 延迟路径
- 假推进路径
- 名义成立但内部空化路径
- 二次启动路径

- 单线程
