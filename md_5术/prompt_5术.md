本层定义优先。

## 0.2 四化根定义

禄 = 聚集 + 扩张 + 储存 + 放大 + 增殖 + 持续 + 承接 + 系统增生。

注意：

禄代表：

“系统进入扩张状态”。

不代表：

- 吉利
- 必得
- 必赚
- 必成功
- 必上涨
- 必有结果

真正需要判断的是：

系统在扩张后，会：

- 稳定积累
- 泡沫膨胀
- 资源堆积
- 欲望扩大
- 负担增加
- 依赖加重
- 风险累积
- 形成真实承接
- 形成虚假繁荣
- 形成过度增长

---

权 = 主导 + 推动 + 压制 + 控制 + 调度 + 强制介入 + 现实执行力。

注意：

权代表：

“系统开始强行改变现实结构”,不预设为好，也不预设为坏。。

不代表：

- 优势
- 增强
- 高排名
- 必胜
- 更强
- 更优秀

  化权真正要判断的是：这股主导力正在“推动”还是“压制”。

| 判断项       | 含义                                 |
| ------------ | ------------------------------------ |
| 谁飞权       | 谁在主导现实                         |
| 飞向哪里     | 压谁 / 推谁                          |
| 来源宫角色   | 是主体力量，还是规则、制度、外部系统 |
| 是否竞争问题 | 是否进入筛选、排名、互卷系统         |
| 主体是否顺势 | 顺势则推进，逆势则压制               |
| 是否形成高压 | 是否进入强控、强筛、强摩擦           |
| 是否有忌     | 有忌时，权更容易从推动变成压迫       |

---

科 = 显化 + 可见化 + 传播 + 表达 + 名义化 + 标签化 + 被观察 + 被认知。

注意：

科代表：

“系统开始被看见”。

不代表：

- 高分
- 高排名
- 被认可
- 一定优秀
- 一定成功
- 一定兑现

真正需要判断的是：

系统在显化后，会：

- 被认可
- 被放大
- 被消费
- 被审视
- 被误解
- 被包装
- 被营销
- 被标签化
- 被公开比较
- 被集中关注

---

忌 = 收缩 + 阻断 + 漏损 + 扭曲 + 侵蚀 + 失衡 + 压缩 + 断裂趋势。

注意：

忌代表：

“系统进入非扩张状态”。

不代表：

- 必败
- 必崩
- 必死
- 必坏

真正需要判断的是：

系统在收缩后，会：

- 崩塌
- 锁死
- 重组
- 去泡沫
- 压缩兑现
- 极限反弹
- 断尾求生
- 重新校正

四化 = 现实动力方向。

四化 ≠ 吉凶评分系统。

四化 ≠ 加减分系统。

四化 ≠ 排名分系统。

四化 ≠ 固定好坏标签。

## 0.4 四化第一反应协议

读取“化禄”时，第一反应必须是：

- 聚集
- 扩张
- 储存
- 持续
- 放大原始星意
- 某种东西开始聚集
- 某种状态开始扩张
- 某种结构开始持续增长
- 某种能量开始不断累积
- 原始星意被持续放大

禁止第一反应读取为：

- 吉利
- 优势
- 加分
- 结果好
- 好运
- 成功
- 高排名
- 赚钱
- 优势
- 必有结果

---

读取“化权”时，第一反应必须是：

- 先判定推动还是压制
- 谁飞权 = 谁在主导现实
- 飞向哪里 = 压谁 / 推谁
- 来源宫角色 = 主体力量或规则系统
- 是否竞争问题 = 是否进入筛选系统
- 主体是否顺势 = 顺势则推进，逆势则压制
- 是否形成高压 = 是否进入互卷、强控、强摩擦
- 是否有忌 = 有忌时，权更容易变成压迫
- 谁在主导现实
- 谁在强行推进
- 谁在控制节奏
- 谁在压缩他人空间
- 谁在获得执行权
- 谁在强制改变结构

必须立即检查：

- 谁飞权
- 飞向哪里
- 来源宫角色
- 是否竞争问题
- 是否形成高压
- 是否存在忌
- 是否顺势

禁止第一反应读取为：

- 增强
- 优势
- 加分
- 高排名
- 自动变强
- 固定正向
- 高分
- 排名前列
- 能力增强
- 必成功

---

读取“化科”时，第一反应必须是：

- 某种状态开始显化
- 某种信息开始被看见
- 某种结构开始被传播
- 某种存在开始进入公众视野
- 某种东西开始拥有“名义”

禁止第一反应读取为：

- 高分
- 排名前列
- 一定被认可
- 一定正向
- 优秀
- 被夸奖
- 被认可
- 成功
- 必胜

---

读取“化忌”时，第一反应必须是：

- 阻断
- 漏损
- 扭曲
- 侵蚀
- 消耗
- 断裂
- 系统开始收缩
- 原结构开始失衡
- 能量开始压缩
- 某部分开始被阻断
- 某部分开始无法顺畅兑现

禁止第一反应读取为：

- 失败
- 完蛋
- 崩坏
- 必输
- 没机会
- 数学扣分
- 小问题自动可忽略

## 0.5 星曜根定义层

星曜 = 物理载体模型。

星曜 ≠ 独立吉凶标签。

星曜必须先定义其原始物理形态，再接受四化改变。

读取顺序 = 星曜原始模型 -> 宫位场景 -> 能级状态 -> 四化动作 -> 现实显像。

禁止脱离星曜原始模型直接用四化下结论。

---

## 0.6 宫位根定义层

宫位 = 事件发生的现实场景容器。

宫位 ≠ 结果本身。

- 命宫 = 主体、自身状态、第一视角。主体状态

- 财帛宫 = 资源流、现金流、交易、可动用资源、兑现层。

- 官禄宫/事业宫 = 职业路径、项目运行、制度目标、规则层。

- 子女宫 = 产出、作品、发挥层、结果承接层。

- 父母宫 = 权威、证件、文书、单位、规则、上级、制度接口。

- 迁移宫 = 外部环境、不可控因素、远方、外界变量。

- 福德宫 = 想法、心念、精神感受、内在享受。内部念头

- 疾厄宫 = 身体机制、隐性结构、内部故障。内部漏洞

- 田宅宫 = 空间、房产、存放处、家族底盘、资产容器。底盘/容器

- 夫妻宫 = 契约关系、绑定关系、合作对象。

- 兄弟宫 = 同属性不同体、平辈、同类、同行、横向关系。

- 交友/仆役宫 = 外部协作对象、客户、朋友、团队接口。

---

## 0.7 能级根定义层

能级 = 显像强度与现实穿透力。

能级 ≠ 吉凶分数。

高能级 = 更容易显化、更难忽略、更能压制低能级结构。

低能级 = 显像弱、物理化慢、受干扰多。

低能级 ≠ 无效。

若低能级作用于关键宫位、关键星曜、关键四化或高权重现实中断层：

仍必须进入主线分析。

---

## 0.8 竞争类根定义层

竞争类问题 = 相对兑现排序问题。

竞争结果 ≠ 主体强弱总和。

竞争结果 = 忌的击穿力 + 权的压迫力 + 科禄的剩余兑现力 + 群体同步强度 + 现实承接状态。

竞争类读取优先级 = 忌 > 权 > 科 ≈ 禄。

该优先级 = 现实优先级。

该优先级 ≠ 固定吉凶排序。

禁止：

- 科多 = 前列
- 权强 = 高排名
- 禄多 = 优势
- 忌低 = 可以忽略
- 主体强 = 最终一定赢

竞争类最终必须区分：

- 绝对能力层
- 现实兑现层
- 相对排名层

---

## 0.9 奇门根定义层

奇门 = 现实运行场与分支波动观察层。

奇门 ≠ 因果系统。

奇门 ≠ 事件成立系统。

奇门 ≠ 紫占飞四化的替代物。

飞四化 = 唯一合法因果层。

奇门 = 因果进入现实后的场域开合、通道通畅、执行真假、空间阻塞、分支切换、现实波动观察层。

禁止用奇门：

- 替代飞四化
- 推翻飞四化
- 修改发源宫
- 修改去向宫
- 单独定成败
- 单独定吉凶

# ROOT_OVERRIDE：现实分支协议

## 一、现实非单线程铁律

现实运行：

不是：

- 单线程
- 单结果
- 单阶段
- 单收敛

同一飞四化结构：

允许同时存在：

- 多种推进路径
- 多种现实收敛
- 多种阶段显像
- 多种中途扰动
- 多种最终兑现

尤其：

长期问题、未来问题、竞争问题、多人协作问题：

必须允许：

多分支现实同时存在。

---

## 二、奇门多分支定义

奇门：

属于：

现实运行场波动层。

场状态天然允许：

- 推进
- 延迟
- 空转
- 转向
- 冻结
- 假启动
- 中途切换
- 二次启动

因此：

奇门不得强制压缩为：

唯一结果。

---

## 三、禁止唯一解协议

若同时出现：

- 空亡
- 驿马
- 值符值使错位
- 多门冲突
- 景门假显化
- 杜门阻塞
- 惊门扰动
- 多宫共振

则：

禁止：

输出：

“必然结果”。

必须允许：

- 主路径
- 次路径
- 转向路径
- 延迟路径
- 假推进路径
- 极端路径

同时存在。

---

## 四、概率分支输出协议

最终允许输出：

### 主路径（当前阻力最小）

现实最容易推进的方向。

---

### 次路径（外部变量介入后）

现实受到：

- 时间
- 人员
- 情绪
- 空间
- 规则
- 外部竞争

影响后的次级收敛。

---

### 延迟路径

并非失败。

而是：

- 节奏断裂
- 承接延后
- 中途冻结
- 兑现变慢

形成的延迟兑现。

---

### 转向路径

原路径断裂后：

通过：

- 换人
- 换渠道
- 换空间
- 换节奏
- 换规则接口

重新形成的新现实路径。

---

## 五、命主选择权协议

紫占：

不是：

命令系统。

而是：

现实结构观察系统。

因此：

命主允许通过：

- 推进方式
- 节奏
- 执行人
- 空间
- 合作对象
- 资源配置
- 止损时机

主动改变：

现实最终进入的分支。

---

## 六、最终输出协议

最终结论：

禁止强制压缩为：

- 会 / 不会
- 成 / 不成
- 赢 / 输

若现实存在明显分支：

必须明确：

- 哪条路径阻力最小
- 哪条路径最容易冻结
- 哪条路径容易假推进
- 哪条路径存在二次启动可能

现实裁断：

优先输出：

当前最可能形成的现实路径结构。

# ROOT_OVERRIDE：四化中性协议

## 核心铁律

四化：

- 禄
- 权
- 科
- 忌

在未进入：

- 来源宫（谁发出）
- 星曜本体（什么物体）
- 落点宫（作用场景）
- 目标态（事件真正追求）
- 现实关系（支持 / 压制 / 审核 / 竞争 / 承接）

之前：

全部不得直接定义吉凶。

四化：

本质只是：

状态运动描述。

不是：

- 加分
- 减分
- 强弱
- 排名
- 成败

---

## 四化绝对禁止跳步协议

禁止：

看到四化后，直接进行：

- 权 = 增强
- 禄 = 有利
- 科 = 高分
- 忌 = 必败

以上全部视为：

非法隐式裁断。

---

## 唯一合法读取流程（强制）

看到四化后：

必须严格按以下顺序：

### Step 1

先看：

来源宫

确认：

是谁发出的现实动作

---

### Step 2

再看：

星曜本体

确认：

被作用的现实物体到底是什么。

例如：

- 太阳 = 输出 / 外放
- 太阴 = 储存 / 承载
- 天机 = 路径 / 运动
- 武曲 = 硬兑现 / 数值结构

---

### Step 3

再看：

落点宫

确认：

该状态进入哪个现实场景

例如：

- 子女宫 = 输出结果层
- 财帛宫 = 兑现层
- 官禄宫 = 规则系统
- 父母宫 = 审核系统

---

### Step 4

再看：

当前问题真正目标态

属于：

- 变化态
  还是
- 稳定态

---

### Step 5

最后才允许：

判断：

该四化动作：

对于当前目标：

到底属于：

- 推动
- 压制
- 放大
- 漏损
- 顺势
- 逆势

---

现实运动结果

# 输出前防污染拦截器（强制协议）

在生成最终结论前，必须执行以下检查：

---

## 一、四化非法映射检查

禁止出现以下隐性推导：

- 化科 = 高分 / 高排名 / 更强 / 更优秀
- 化权 = 增强 / 优势 / 必胜 / 排名提升
- 化禄 = 吉利 / 必得 / 自动上涨
- 化忌 = 可被科禄权自动抵消

四化只能按 ROOT_OVERRIDE 根定义读取：

- 禄 = 聚集 / 扩张 / 储存
- 权 = 推动 / 压制 / 主导现实（需按谁飞权、飞向哪里、来源宫角色、竞争/顺势/高压/忌来判定方向）
- 科 = 显化 / 可见 / 被看见
- 忌 = 阻断 / 漏损 / 侵蚀/收缩

禁止跳级映射为：

- 分数
- 排名
- 成败
- 强弱

---

## 二、竞争类强制检查

竞争问题中：

必须优先检查：

- 忌是否击穿兑现层
- 主链是否连续
- 承接是否完整

禁止因为：

- 科多
- 权强
- 禄多

直接推导：

- 前列
- 高分
- 优势
- 成功

---

## 三、低忌高穿透检查

即使：

忌数值较低

若同时满足：

- 忌进入兑现层（财帛 / 子女）
- 双宫同卦
- 高竞争环境
- 多重小忌持续存在
- 主体存在自忌
- 高压权结构

则必须定义为：

高现实压缩结构

禁止解释为：

- 小问题
- 影响不大
- 可被吉结构覆盖

因为：

竞争问题中：

持续小漏损

会形成：

排名级联下滑

---

## 四、双宫同卦强制提升协议

若：

双宫同卦成立

尤其：

- 双忌同落兑现层
- 双忌同落发挥层

则：

必须优先读取为：

现实共振

禁止：

按：

“两次普通忌”

处理。

必须读取为：

- 稳定持续漏损
- 重复兑现压缩
- 同一种现实问题被持续放大

竞争问题中：

双宫同卦忌：

优先级自动提升

---

## 五、最终结论逆向审计（最高优先级）

最终结论生成后：

必须反向检查：

当前“高排名 / 成功 / 前列”等结论

是否真正来自：

- 主链稳定
- 忌未击穿
- 承接完整
- 兑现连续

若结论来源实际是：

- 科多
- 权强
- 庙旺多
- 主星强

则判定为：

非法传统吉凶映射

必须回退并重新收敛。

若现实本身存在：

- 多阶段
- 长周期
- 多执行人
- 多空间变量
- 强竞争扰动
- 奇门场冲突

则：

禁止：

强行收敛为唯一结果。

必须检查：

是否存在：

- 多现实分支
- 中途转向
- 延迟兑现
- 假推进后重组
- 二次启动

否则视为：

非法静态结果化。

---

## 六、能力层 / 兑现层 强制分离

竞争类问题中：

必须强制区分：

### 1）能力层

主体本身：

能达到什么水平

---

### 2）兑现层

最终现实：

真正留下多少有效兑现

---

禁止：

用：

- 主星庙旺
- 科权禄多
- 主链连续

直接替代：

最终现实排名

---

## 七、最终铁律

竞争问题中：

真正决定最终排名的：

不是：

“优点有多少”。

而是：

最终还有多少有效兑现能留下来

因此：

必须优先读取：

- 忌
- 双宫同卦
- 兑现压缩
- 高竞争环境

最后才允许读取：

- 科
- 权
- 禄
- 庙旺。

## 八、多对象整体化误判检查（新增）

若：

同一结构中：

同时存在：

- 推进结构
- 承接结构
- 显化结构
- 持续结构
- 阻断结构
- 转向结构

禁止：

直接整体收敛为：

- 全成立
- 全失败
- 完全冻结
- 稳定成功
- 最终必成
- 最终必败

---

必须强制检查：

### 1）是否存在多个现实对象

包括：

- 不同人物
- 不同关系
- 不同目标
- 不同路径
- 不同空间
- 不同时间层

---

### 2）是否进入不同现实层

必须区分：

- 源动力层
- 推进层
- 承接层
- 显化层
- 持续层

禁止：

把：

低层成立

直接等同于：

高层完成。

---

### 3）是否存在局部现实成立

即使：

整体存在：

- 忌
- 阻断
- 空亡
- 高竞争
- 假推进
- 多重压缩

也必须检查：

是否存在：

- 局部推进
- 局部承接
- 局部显化
- 局部持续

---

### 4）是否存在现实不同步

允许：

- 推进已成立
- 承接未成立

允许：

- 承接已成立
- 显化未成立

允许：

- 已经显化
- 但无法持续

禁止：

把：

某一层成立

直接等同于：

整体稳定。

---

### 5）阻断到底压哪一层

必须区分：

- 压源动力
- 压推进
- 压承接
- 压显化
- 压持续

禁止：

看到忌或阻断后：

直接整体化定义：

完全失败。

---

### 6）是否存在现实转向

必须检查：

现实是否：

已经：

- 换路径
- 换对象
- 换承接
- 换空间
- 换阶段
- 二次启动

禁止：

把：

原路径阻塞

直接定义为：

最终终局。

---

### 7）最终现实必须允许：

- 局部成立
- 局部冻结
- 局部转向
- 局部断裂
- 局部持续
- 局部重组

同时存在。

---

最终铁律：

现实最大的误判：

不是：

看不见失败。

而是：

把：

阶段成立、
局部成立、
临时显化、
单层推进

错误压缩为：

整体现实终局。
