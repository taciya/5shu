## 0.2 四化根定义

禄 = 聚集 + 扩张 + 储存 + 放大 + 增殖 + 持续 + 承接 + 系统增生。

注意：

禄代表：

“系统进入扩张状态”。

不代表：

- 吉利
- 必得
- 必赚
- 必成功
- 必上涨
- 必有结果

真正需要判断的是：

系统在扩张后，会：

- 稳定积累
- 泡沫膨胀
- 资源堆积
- 欲望扩大
- 负担增加
- 依赖加重
- 风险累积
- 形成真实承接
- 形成虚假繁荣
- 形成过度增长

---

权 = 主导 + 推动 + 压制 + 控制 + 调度 + 强制介入 + 现实执行力。

注意：

权代表：

“系统开始强行改变现实结构”,不预设为好，也不预设为坏。。

不代表：

- 优势
- 增强
- 高排名
- 必胜
- 更强
- 更优秀

  化权真正要判断的是：这股主导力正在“推动”还是“压制”。

| 判断项       | 含义                                 |
| ------------ | ------------------------------------ |
| 谁飞权       | 谁在主导现实                         |
| 飞向哪里     | 压谁 / 推谁                          |
| 来源宫角色   | 是主体力量，还是规则、制度、外部系统 |
| 是否竞争问题 | 是否进入筛选、排名、互卷系统         |
| 主体是否顺势 | 顺势则推进，逆势则压制               |
| 是否形成高压 | 是否进入强控、强筛、强摩擦           |
| 是否有忌     | 有忌时，权更容易从推动变成压迫       |

---

科 = 显化 + 可见化 + 传播 + 表达 + 名义化 + 标签化 + 被观察 + 被认知。

注意：

科代表：

“系统开始被看见”。

不代表：

- 高分
- 高排名
- 被认可
- 一定优秀
- 一定成功
- 一定兑现

真正需要判断的是：

系统在显化后，会：

- 被认可
- 被放大
- 被消费
- 被审视
- 被误解
- 被包装
- 被营销
- 被标签化
- 被公开比较
- 被集中关注

---

忌 = 收缩 + 阻断 + 漏损 + 扭曲 + 侵蚀 + 失衡 + 压缩 + 断裂趋势。

注意：

忌代表：

“系统进入非扩张状态”。

不代表：

- 必败
- 必崩
- 必死
- 必坏

真正需要判断的是：

系统在收缩后，会：

- 崩塌
- 锁死
- 重组
- 去泡沫
- 压缩兑现
- 极限反弹
- 断尾求生
- 重新校正

四化 = 现实动力方向。

四化 ≠ 吉凶评分系统。

四化 ≠ 加减分系统。

四化 ≠ 排名分系统。

四化 ≠ 固定好坏标签。

## 0.5 星曜根定义层

星曜 = 物理载体模型。

星曜 ≠ 独立吉凶标签。

星曜必须先定义其原始物理形态，再接受四化改变。

读取顺序 = 星曜原始模型 -> 宫位场景 -> 能级状态 -> 四化动作 -> 现实显像。

禁止脱离星曜原始模型直接用四化下结论。

## 0.6 宫位根定义层

宫位 = 事件发生的现实场景容器。

宫位 ≠ 结果本身。

- 命宫 = 主体、自身状态、第一视角。

- 财帛宫 = 资源流、现金流、交易、可动用资源、兑现层。

- 官禄宫/事业宫 = 职业路径、项目运行、制度目标、规则层。

- 子女宫 = 产出、作品、发挥层、结果承接层。

- 父母宫 = 权威、证件、文书、单位、规则、上级、制度接口。

- 迁移宫 = 外部环境、不可控因素、远方、外界变量。

- 福德宫 = 想法、心念、精神感受、内在享受。

- 疾厄宫 = 身体机制、隐性结构、内部故障。

- 田宅宫 = 空间、房产、存放处、家族底盘、资产容器。

- 夫妻宫 = 契约关系、绑定关系、合作对象。

- 兄弟宫 = 同属性不同体、平辈、同类、同行、横向关系。

- 交友/仆役宫 = 外部协作对象、客户、朋友、团队接口。

---

## 0.7 能级根定义层

能级 = 显像强度与现实穿透力。

能级 ≠ 吉凶分数。

高能级 = 更容易显化、更难忽略、更能压制低能级结构。

低能级 = 显像弱、物理化慢、受干扰多。

低能级 ≠ 无效。

若低能级作用于关键宫位、关键星曜、关键四化或高权重现实中断层：

仍必须进入主线分析。

---

## 0.8 竞争类根定义层

竞争类问题 = 相对兑现排序问题。

竞争结果 ≠ 主体强弱总和。

竞争结果 = 忌的击穿力 + 权的压迫力 + 科禄的剩余兑现力 + 群体同步强度 + 现实承接状态。

竞争类读取优先级 = 忌 > 权 > 科 ≈ 禄。

该优先级 = 现实优先级。

该优先级 ≠ 固定吉凶排序。

禁止：

- 科多 = 前列
- 权强 = 高排名
- 禄多 = 优势
- 忌低 = 可以忽略
- 主体强 = 最终一定赢

竞争类最终必须区分：

- 绝对能力层
- 现实兑现层
- 相对排名层

---

## 0.9 奇门根定义层

奇门 = 现实运行场观察层。

奇门 ≠ 因果系统。

奇门 ≠ 事件成立系统。

奇门 ≠ 紫占飞四化的替代物。

飞四化 = 唯一合法因果层。

奇门 = 因果进入现实后的场域开合、通道通畅、执行真假、空间阻塞观察层。

禁止用奇门：

---

## 一、四化非法映射检查

禁止出现以下隐性推导：

- 化科 = 高分 / 高排名 / 更强 / 更优秀
- 化权 = 增强 / 优势 / 必胜 / 排名提升
- 化禄 = 吉利 / 必得 / 自动上涨
- 化忌 = 可被科禄权自动抵消

四化只能按 ROOT_OVERRIDE 根定义读取：

- 禄 = 聚集 / 扩张 / 储存
- 权 = 推动 / 压制 / 主导现实（需按谁飞权、飞向哪里、来源宫角色、竞争/顺势/高压/忌来判定方向）
- 科 = 显化 / 可见 / 被看见
- 忌 = 阻断 / 漏损 / 侵蚀/收缩

禁止跳级映射为：

- 分数
- 排名
- 成败
- 强弱

---

## 二、竞争类强制检查

竞争问题中：

必须优先检查：

- 忌是否击穿兑现层
- 主链是否连续
- 承接是否完整

禁止因为：

- 科多
- 权强
- 禄多

直接推导：

- 前列
- 高分
- 优势
- 成功

---

## 三、低忌高穿透检查（新增关键）

即使：

忌数值较低。

若同时满足：

- 忌进入兑现层（财帛 / 子女）
- 双宫同卦
- 高竞争环境
- 多重小忌持续存在
- 主体存在自忌
- 高压权结构

则必须定义为：

高现实压缩结构

禁止解释为：

- 小问题
- 影响不大
- 可被吉结构覆盖

因为：

竞争问题中：

持续小漏损
会形成：

排名级联下滑。

---

## 四、双宫同卦强制提升协议（新增关键）

若：

双宫同卦成立。

尤其：

- 双忌同落兑现层
- 双忌同落发挥层

则：

必须优先读取为：

现实共振

禁止：

按：

“两次普通忌”

处理。

必须读取为：

- 稳定持续漏损
- 重复兑现压缩
- 同一种现实问题被持续放大

竞争问题中：

双宫同卦忌：

优先级自动提升。

---

## 五、最终结论逆向审计（最高优先级）

最终结论生成后：

必须反向检查：

当前“高排名 / 成功 / 前列”等结论，

是否真正来自：

- 主链稳定
- 忌未击穿
- 承接完整
- 兑现连续

若结论来源实际是：

- 科多
- 权强
- 庙旺多
- 主星强

则判定为：

非法传统吉凶映射

必须回退并重新收敛。

---

## 六、能力层 / 兑现层 强制分离（新增关键）

竞争类问题中：

必须强制区分：

### 1）能力层

主体本身：

能达到什么水平。

---

### 2）兑现层

最终现实：

真正留下多少有效兑现。

---

禁止：

用：

- 主星庙旺
- 科权禄多
- 主链连续

直接替代：

最终现实排名。

---

## 七、最终铁律

竞争问题中：

真正决定最终排名的：

不是：

“优点有多少”。

而是：

最终还有多少有效兑现能留下来。

因此：

必须优先读取：

- 忌
- 双宫同卦
- 兑现压缩
- 高竞争环境

最后才允许读取：

- 科
- 权
- 禄
- 庙旺。
