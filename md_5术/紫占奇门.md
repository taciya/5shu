# ROOT_OVERRIDE：四化中性协议（新增最高优先级覆盖层）

## 核心铁律

四化：

- 禄
- 权
- 科
- 忌

在未进入：

- 来源宫（谁发出）
- 星曜本体（什么物体）
- 落点宫（作用场景）
- 目标态（事件真正追求）
- 现实关系（支持 / 压制 / 审核 / 竞争 / 承接）

之前：

全部不得直接定义吉凶。

四化：

本质只是：

> 状态运动描述。

不是：

- 加分
- 减分
- 强弱
- 排名
- 成败

---

## 四化绝对禁止跳步协议

禁止：

看到四化后，

直接进行：

- 权 = 增强
- 禄 = 有利
- 科 = 高分
- 忌 = 必败

以上全部视为：

非法隐式裁断。

---

## 唯一合法读取流程（强制）

看到四化后：

必须严格按以下顺序：

### Step 1

先看：

来源宫。

确认：

是谁发出的现实动作。

---

### Step 2

再看：

星曜本体。

确认：

被作用的现实物体到底是什么。

例如：

- 太阳 = 输出 / 外放
- 太阴 = 储存 / 承载
- 天机 = 路径 / 运动
- 武曲 = 硬兑现 / 数值结构

---

### Step 3

再看：

落点宫。

确认：

该状态进入哪个现实场景。

例如：

- 子女宫 = 输出结果层
- 财帛宫 = 兑现层
- 官禄宫 = 规则系统
- 父母宫 = 审核系统

---

### Step 4

再看：

当前问题真正目标态。

属于：

- 变化态
  还是
- 稳定态

---

### Step 5

最后才允许：

判断：

该四化动作：

对于当前目标：

到底属于：

- 推动
- 压制
- 放大
- 漏损
- 顺势
- 逆势

---

## 四化中性铁律（新增）

四化本身：

永远不携带：

- 吉
- 凶

永远是：

现实运动结果。

到底是在：

  还是
- 压制主体

锁定 / 固化 / 终止变化。

反而可能属于：

### 1. 禁止抽象吉凶

裁断时禁止直接输出“吉、凶、好、坏、旺、衰”作为最终结论。必须转换为可成像、可验证的状态描述：

| 禁止输出 | 必须改写为                                           |
| :------- | :--------------------------------------------------- |
| 吉       | 目标得以推进、状态可承载、资源能接住、路径可持续     |
| 凶       | 当前状态被阻断、承载不足、资源漏失、路径中断或变形   |
| 好       | 对所问目标形成支持                                   |
| 坏       | 对所问目标形成消耗、阻断、错位或过载                 |
| 有贵人   | 出现实质帮助、间接帮助、权限开放、资源转介、技术支持 |
| 有问题   | 出现缺失、过度、停滞、噪音、压力、误判、延迟、断裂   |

### 2. 禁止脱离所问事项

星曜成像必须与所断事项精准匹配。
同一组星曜，在不同问题里不能复用同一结论。

例如：

- 天机化忌问“正在行驶的车辆”：表示运动终止、急刹、停滞。
- 天机化忌问“需要刹车避险”：表示制动完成、运动被终止。
- 太阴化禄问“快乐”：表示储存的快乐被放大。
- 太阴化禄问“烦恼”：表示储存的烦恼被放大。

例外协议：

若：

盘面出现：

高权重现实主象。

且：

该现实象：

已经足以：

中断、
覆盖、
替代、
压制

原事件运行基础。

则：

允许：

优先输出现实主象。

不得：

因为“用户未主动询问”
而压制真实现实结构。

此时：

现实主象：

优先级：

高于事件分支。

### 3. 禁止抛开原始星意看四化

四化不是独立断语。
四化只能作用于：

1. 星曜原始星意。
2. 宫位场景。
3. 庙旺落陷能级。
4. 所问事项目标。

四化的核心作用是：

- 调级：改变星曜当前能级。
- 追路：追踪事件发展路径。
- 连接：连接相关宫位。
- 定应期：标记状态变化发生或终止的节点。

## 四、裁断总流程

### Step 1：事件定用宫

先判断用户问的是哪一类对象：

| 事件     | 用宫                                         |
| :------- | :------------------------------------------- |
| 人       | 命宫、身宫、福德宫、迁移宫                   |
| 事业     | 官禄宫、财帛宫、迁移宫、父母宫               |
| 钱财     | 财帛宫、田宅宫、福德宫、官禄宫               |
| 感情     | 夫妻宫、福德宫、命宫、迁移宫                 |
| 学业考试 | 官禄宫、父母宫、命宫、福德宫                 |
| 健康     | 疾厄宫、命宫、福德宫、父母宫                 |
| 家宅资产 | 田宅宫、财帛宫、父母宫                       |
| 证件合约 | 父母宫、官禄宫、文昌、文曲、右弼、封诰、天官 |
| 迁动出行 | 迁移宫、天机、天马、七杀、火星、地空、地劫   |
| 寻物     | 田宅宫、财帛宫、太阴、巨门、地劫、阴煞       |

### Step 2：宫位定场景

宫位不是结论，而是星曜显化的容器。

| 宫位        | 场景                                           |
| :---------- | :--------------------------------------------- |
| 命宫        | 主体、自身状态、第一视角                       |
| 兄弟宫      | 同属性不同体，平辈、同类、同事、同行、横向关系 |
| 夫妻宫      | 契约关系、绑定关系、合作/配偶对象              |
| 子女宫      | 产出、后代、作品、下级、项目结果               |
| 财帛宫      | 资源流、现金流、交易、可动用资源               |
| 疾厄宫      | 身体机制、隐性结构、内部故障                   |
| 迁移宫      | 外部环境、不可控因素、政策、远方、外界变量     |
| 交友/仆役宫 | 外部协作对象、客户、朋友、团队接口             |
| 官禄/事业宫 | 职业路径、项目运行、制度目标、工作状态         |
| 田宅宫      | 空间、房产、存放处、家族底盘、资产容器         |
| 福德宫      | 想法、心念、精神感受、兴趣、内在享受           |
| 父母宫      | 权威、证件、文书、单位、规则、上级、政府       |

### Step 3：大星定框架

大星给出事件的主要成像框架。

示例：

- 天机：运动、道路、规则、技术、发展路径。
- 太阴：储存、容纳、持续、女性、水、夜间。
- 七杀：线性结构、直线、血管、电路、屏幕线、发展线。
- 天府：空间、区域、房屋、系统边界。

### Step 4：小星定细节

小星负责改变主星性质，补充细节形态。

示例：

- 七杀 + 左辅：多条线。
- 七杀 + 陀罗：缠绕线团。
- 七杀 + 地劫：断线、线性结构中断。
- 太阴 + 铃星：苦水、储存烦恼。
- 太阴 + 天喜：糖水、储存快乐。
- 天梁 + 火星：火柱子、支撑物带火/热/急。
- 巨门 + 地劫：门洞、漏洞、沟通失效、言不由衷。
- 破军 + 地劫：突破失败、打击落空。
- 天机 + 地劫：白费力气、运动/路径出现空耗。
- 太阳 + 地劫：关注但漏看、照见但缺口存在。
- 贪狼 + 地劫：欲望落空。
- 武曲 + 地劫：钱财损失、硬物缺口。

### Step 5：四化定变化与应期

四化不能单独定性。
必须写成：

> 星曜原始状态 + 宫位场景 + 能级 + 四化动作 = 当前状态变化。

---

#### 5.x 四化来源宫正负修正协议（竞争类强制）

四化本身：

不是固定吉凶。

四化只能定义：

- 禄 = 聚集 / 扩张 / 储存
- 权 = 推动 / 压制 / 控制 / 摩擦（需按谁飞权、飞向哪里、来源宫角色、竞争/顺势/高压/忌来判定方向）
- 科 = 显化 / 被看见 / 传播
- 忌 = 阻断 / 漏损 / 侵蚀

禁止：

脱离来源宫，

直接把：

- 禄
- 权
- 科

读取为：

固定正向。

---

##### 5.x.1 来源宫优先原则

任何飞四化：

必须先确认：

1）谁飞出（来源宫）

2）来源宫在当前问题中的现实角色

3）来源宫与目标宫之间属于：

- 支持
- 压制
- 竞争
- 审核
- 消耗
- 对抗
- 规则控制

之后：

才能定义：

该四化在目标宫中的真实方向。

禁止：

跳过来源宫，

直接根据：

- 权高
- 科多
- 禄强

生成：

- 高排名
- 更优秀
- 更强
- 自动有利

---

##### 5.x.2 竞争类问题特殊规则

竞争类问题中：

以下宫位：

默认具有：

“规则压制属性”

包括：

- 官禄宫
- 父母宫
- 交友宫（竞争群体时）
- 兄弟宫（同级竞争时）

因此：

这些宫位飞“权”进入：

- 子女宫
- 财帛宫
- 命宫

时：

必须优先检查：

是否形成：

- 规则压迫
- 排名压缩
- 高压筛选
- 前列互卷
- 稳定兑现折损

禁止：

直接读取为：

- 成绩增强
- 排名提升
- 自动加分

---

##### 5.x.3 官禄飞权特殊协议（强制）

竞争类问题中：

若：

官禄宫飞权进入：

- 子女宫（成绩结果）
- 财帛宫（分数兑现）

则：

默认优先读取为：

“排名系统对结果层施压”

其现实表现包括：

- 高压竞争
- 名次压缩
- 前列互卷
- 规则筛选
- 稳定发挥难度增加
- 顶层兑现率下降

禁止：

直接解释为：

- 成绩更强
- 自动前列
- 排名提升

除非：

同时满足：

- 兑现层无忌
- 官禄系统无重压
- 主链无断裂
- 结果层无压缩

否则：

必须视为：

“竞争压迫型权”

而不是：

“增益型权”

---

##### 5.x.4 来源宫决定四化方向

同一种四化：

来源不同，

现实方向可能完全相反。

例如：

###### 命宫飞权

更偏：

- 主观推动
- 自身执行
- 主体发力

---

###### 官禄宫飞权

更偏：

- 规则压迫
- 制度筛选
- 排名竞争
- 高压互卷

---

###### 交友宫飞权

更偏：

- 外部竞争
- 群体挤压
- 同行压迫

---

###### 父母宫飞权

更偏：

- 审核限制
- 上级压力
- 文书卡控
- 制度要求

---

##### 5.x.5 竞争结果最终校验

竞争类最终收敛前：

必须检查：

1）四化来源宫

2）来源宫现实角色

3）目标宫是否属于：

- 结果层
- 兑现层
- 排名层

4）该四化是否实际形成：

- 压缩
- 阻断
- 互卷
- 高压筛选
- 稳定兑现下降

禁止：

只因为：

- 权强
- 科多
- 禄多

直接提高：

- 排名
- 百分位
- 覆盖率

---

##### 5.x.6 最终执行铁律

竞争类问题中：

“来源宫优先级”

高于：

“四化表面性质”

因此：

- 官禄飞权 ≠ 自动增强
- 父母飞权 ≠ 自动有利
- 交友飞权 ≠ 自动推进

必须结合：

来源宫现实角色，

重新定义：

该四化在现实中的真正方向。

### Step 5.0：星曜主导协议

⚠️ 四化：

不能脱离星曜本体单独裁断。

真正的读取顺序：

必须是：

> 星曜本体
> → 四化动作
> → 状态变化
> → 现实显像

禁止：

直接读取：

- 忌 = 失败
- 权 = 增强
- 禄 = 吉利
- 科 = 高分

之后：

再让星曜“修饰结果”。

这是错误读取。

---

#### 一、星曜才是现实物理主体

星曜：

决定：

> 现实中的“那个东西”
> 到底是什么。

例如：

| 星曜 | 本体现实           |
| ---- | ------------------ |
| 廉贞 | 抓、锁、囚、粘     |
| 巨门 | 门、权限、通道     |
| 武曲 | 金属、钱、硬结构   |
| 天机 | 路径、运动、变化   |
| 文昌 | 偏斜传播、文书载体 |
| 禄存 | 固化堆积物         |
| 破军 | 破坏、突破、重组   |

四化：

不能改变：

该物体本身。

只能改变：

它的：

- 运动方向
- 能量状态
- 运行趋势
- 显化模式

---

#### 二、四化真正作用（新增关键）

四化：

本质不是：

结果标签。

而是：

> 对星曜原始物理状态的动作。

因此：

四化真正作用是：

| 四化 | 真正作用                             |
| ---- | ------------------------------------ |
| 禄   | 放大当前星曜状态                     |
| 权   | 强制主导当前星曜状态                 |
| 科   | 让当前星曜状态显化/缓冲              |
| 忌   | 让当前星曜状态停止变化/收缩/终止运动 |

⚠️ 注意：

化忌：

终止的。

首先是：

> “运动状态”。

不是：

自动终止结果。

---

#### 三、禁止四化覆盖星曜本体（新增铁律）

禁止：

出现：

> 廉贞忌 = 完全断裂

因为：

廉贞本体：

不是“断”。

而是：

抓、锁、囚。

因此：

廉贞忌：

只能是：

- 锁死
- 固化
- 停止流动
- 被绑定

而不能：

直接变成：

“完全不存在”。

---

同理：

⚠️ 巨门忌：

优先是：

- 门关闭
- 权限锁死
- 通道停止

不是：

“事情消失”。

---

⚠️ 武曲忌：

优先是：

- 资金冻结
- 硬结构停滞
- 钱流停止

不是：

“钱完全没了”。

---

⚠️ 天机忌：

才更接近：

- 路径停止
- 运动中断
- 推进断流。

因为：

天机本体：

本来就是“运动”。

---

#### 四、最终铁律（新增最高优先级）

⚠️ 四化：

永远只能：

改变：

星曜的状态。

不能：

覆盖：

星曜本体。

真正决定：

现实到底是什么的。

永远首先是：

> 星曜本身。

四化：

只是决定：

这个东西：

- 怎么动
- 往哪里动
- 是否停止运动
- 是否被放大
- 是否被主导
- 是否被显化。

---

---

### Step 5.0-C：目标态协议（新增最高优先级）

⚠️ 四化：

只能描述：

> 星曜状态如何运动。

不能直接定义：

- 成功
- 失败
- 成立
- 不成立

因为：

任何事件：

都存在：

自身真正追求的：

> “目标态”。

而不同事件：

目标态可能完全不同。

---

#### 一、目标态定义（核心）

所有事件：

最终都可以抽象为：

两种目标态：

---

##### 1）变化态

目标：

是：

- 持续变化
- 持续运动
- 持续扩张
- 持续流动
- 持续打开
- 持续推进

此时：

若出现：

- 停止运动
- 固化
- 冻结
- 封闭

则：

更容易形成：

- 阻断
- 停滞
- 推进中断。

---

##### 2）稳定态

目标：

是：

- 固定
- 稳定
- 锁定
- 不再变化
- 停止波动
- 进入确定状态

此时：

若出现：

- 停止运动
- 固化
- 冻结
- 封闭

反而可能意味着：

- 状态稳定
- 目标固定
- 结果收敛
- 进入最终态。

---

#### 二、禁止错误读取（新增铁律）

禁止：

跳过：

“目标态判断”。

直接把：

- 忌
- 冻结
- 固化
- 停止运动

读取为：

- 失败
- 中断
- 不成立。

因为：

同一种：

“停止变化”。

在不同目标态中：

现实意义可能完全相反。

---

#### 三、最终判断顺序（新增关键）

最终裁断时：

必须按以下顺序：

1）星曜本体
（现实物体是什么）

↓

2）四化动作
（该物体如何运动）

↓

3）目标态判断
（当前事件真正追求稳定还是变化）

↓

4）顺逆判断
（当前四化动作是顺目标还是逆目标）

↓

5）最终现实显像

禁止：

跳过：

“目标态判断”。

直接从：

四化动作

推导：

最终结果。

---

#### 四、最终铁律（新增最高优先级）

⚠️ 四化：

永远只描述：

> “状态运动方式”。

真正决定：

该运动：

到底属于：

- 推进
  还是
- 阻断

的。

是：

当前事件的：

> 目标态。

不是：

四化本身。

---

### Step 5.0-D：动态推演边界协议（新增最高优先级）

#### 一、核心铁律

⚠️ 紫占：

允许：

- 动态推演
- 场景映射
- 现实拟象
- 多义收敛
- 合法脑补

因为：

天地象义：

本身属于：

> 现实结构映射系统。

因此：

禁止：

把：

“禁止脑补”

作为运行目标。

真正需要限制的：

是：

> 脑补权限边界。

---

#### 二、合法脑补定义

合法脑补：

只能建立在：

已经确认成立的协议节点之上。

例如：

已经确认：

- 星曜本体
- 四化动作
- 目标态
- 来源宫角色
- 主链方向

之后：

才允许：

进行现实场景映射。

---

#### 三、禁止事项（新增铁律）

禁止：

跳过：

尚未确认的协议节点，

提前收敛：

- 成败
- 淘汰
- 锁定
- 排名
- 是否结束
- 是否成功

禁止：

因为：

- 社会经验
- 常见概率
- AI统计惯性
- “一般来说”
- “通常招聘会...”
- “考试通常...”

提前决定现实方向。

---

#### 四、目标态优先协议（新增关键）

任何：

- 停止
- 终止
- 冻结
- 不再继续
- 流程结束

都必须先检查：

当前事件真正目标：

到底属于：

##### 1）变化态

还是：

##### 2）稳定态

---

若：

事件目标本身：

是：

- 锁定
- 固定
- 绑定
- 成交
- 签约
- 最终确认

则：

“停止继续变化”

可能属于：

> 顺目标完成。

不是：

自动失败。

---

#### 五、契约类特殊协议（新增关键）

夫妻宫：

本质：

不是感情专属。

而是：

> 绑定关系系统。

因此：

在：

- 招聘
- 签约
- 合同
- 合作
- Offer
- 客户锁定

问题中：

夫妻宫：

#### 四、四化计算规则（强制）

四化原始百分比：

只能保留原值。

例如：

- 科95 = 95
- 忌30 = 30

禁止：

任何形式：

- ×2
- ×3
- ×1.5
- “主卦加权”
- “分钟卦翻倍”
- “核心宫增幅”

除非规则文件中明确存在固定公式。

否则全部视为：

> 脑补规则

---

#### 五、星曜亮度兑现协议

##### 1）核心原则

星曜亮度：

属于：

> 星曜能级

因此：

竞争类问题中：

必须检查：

- 庙
- 旺
- 利
- 得
- 平
- 陷

对：

现实兑现层的影响。

且：

⚠️ 允许：

将亮度转换为：

- 数值倍率
- 百分比倍率
- 人工加权

例如：

- 庙 ×1
- 旺 ×.9
- 利 ×.7
- 得 ×.5
- 平 ×.4
- 不 ×.3
- 陷 ×.15

---

##### 2）亮度真正作用范围

亮度只能用于：

> 判断结构兑现稳定度

即：

影响：

- 排名压缩
- 稳定性
- 承载力
- 波动风险
- 真实落地能力

---

##### 3）亮度兑现层定义

###### 庙

代表：

- 高承载
- 高稳定
- 强兑现
- 不易被小忌击穿

竞争问题中：

容易形成：

> 稳定高位结构

---

###### 旺

代表：

- 推动力强
- 现实执行力强
- 竞争持续性较高

但：

仍可能：

被连续忌冲击。

---

###### 利

代表：

- 有发挥能力
- 有竞争力

但：

稳定度不足。

遇：

- 忌
- 自化耗损
- 双冲

时：

容易：

出现：

> 排名压缩

---

###### 得

代表：

- 可运行
- 可成立

但：

承载力有限。

若：

再接：

- 忌
- 自忌
- 断链

则：

容易：

出现：

- 发挥波动
- 中段掉档
- 临场失误

---

###### 平

代表：

- 普通承载
- 普通竞争力

容易：

随环境波动。

---

###### 陷

代表：

- 结构承载不足
- 稳定性弱

即使：

存在：

- 科
- 权
- 禄

也可能：

无法稳定兑现。

---

##### 4）亮度与忌联动规则（强制）

竞争问题中：

必须检查：

> “亮度是否被忌击穿”

例如：

###### 庙 + 小忌

可能：

仍可稳定兑现。

但：

###### 得 + 忌

则容易：

真实掉档。

###### 利 + 自忌

则容易：

出现：

- 临场失误
- 排名回落
- 关键细节失分

---

##### 5）亮度作用边界（强制）

亮度只能用于：

> 百分位压缩修正

不得：

用于：

- 直接定义排名
- 强行推前几
- 数值乘法修正

必须：

先完成：

四化主链分析。

之后：

再进行：

兑现稳定度压缩。

---

#### 六、竞争压缩协议

竞争类问题：

必须考虑：

> 排名压缩

即：

即使结构不错，
也可能因为：

- 强竞争环境
- 前段密集
- 同层人数多
- 星曜亮度承载不足
- 忌击穿兑现层

导致：

实际排名仅：

- 前20%
- 前30%
- 前40%

因此：

禁止：

从“结构偏吉”
直接跳到：
“前几名”

必须：

先落：

> 百分位

再映射排名。

---

#### 七、百分位优先协议

竞争问题：

必须优先输出：

1. 百分位
2. 再输出排名区间

禁止直接：

“第1”
“第3”
“前5”

必须先给：

例如：

- 前10%
- 前25%
- 前40%

再结合班级人数换算。

---

#### 八、结果反推禁止协议

禁止：

先得到结论，
再反向调整：

- 权重
- 倍率
- 阈值
- 映射区间
- 亮度修正

以下行为全部禁止：

- 为了符合前面结论，临时提高倍率
- 为了维持结果，弱化忌
- 为了收敛排名，修改百分位映射
- 根据结果重新定义“科”的意义
- 根据结果重新定义亮度作用

必须：

先固定公式，
后统一计算。

禁止：

边算边改。

### Step 7：双宫同卦（同源共振）协议

#### 一、核心定义

双宫同卦：

是指：

两个不同宫位，

出现：

- 完全相同的飞化结构
- 完全相同的飞化路径
- 完全相同的现实指向
- 完全相同的最终去向

形成：

同一种现实结构，

被两个空间：

同步重复强调。

---

#### 二、双宫同卦铁律

⚠️ 双宫同卦：

不是：

“两次普通飞化”。

而是：

同一种现实问题，

正在被：

两个空间，

同步重复放大。

因此：

属于：

现实共振结构。

---

#### 三、成立条件

##### 条件1：飞化一致

两个宫位：

存在：

- 相同星曜
- 相同四化
- 相同去向

例如：

A宫：

- 武曲忌 → 财帛宫

B宫：

- 武曲忌 → 财帛宫

则：

成立双宫同卦。

---

##### 条件2：现实指向一致

不仅：

飞化一致。

还必须：

现实指向一致。

例如：

都对应：

- 财务损耗
- 成绩兑现压制
- 关系持续耗损

若现实指向不同：

则：

不成立双宫同卦。

---

#### 四、现实权重协议

若：

普通路径
与
双宫同卦

同时存在。

必须：

优先检查：

双宫同卦。

因为：

双宫同卦：

属于：

现实共振。

---

#### 五、共振增强协议

双宫同卦：

会增强：

- 现实热度
- 路径权重
- 收敛影响
- 最终现实影响

因此：

即使：

能级不高。

仍可能：

优先改变现实结果。

---

#### 六、双宫同卦忌

若：

双宫同卦：

为：

化忌。

禁止：

按：

“两次压力”

解释。

必须定义：

同一种现实问题，

正在：

被持续同步放大。

---

#### 七、最终铁律

⚠️ 双宫同卦：

本质：

不是：

数量增加。

而是：

天地正在：

重复强调：

同一种现实结果。

| 白虎 | 清除、肃杀、白色、全歼、格式化           | 可为彻底清理、灭菌、删除。                                              |
| 卷舌 | 信息干扰、谎言、噪音                     | 网络谣言、电磁噪音、口舌干扰。                                          |
| 太岁 | 年度核心枢纽、政策转向、大拐点           | 用于年周期和外部大势。                                                  |
| 晦气 | 能量阻滞点、倒霉气息                     | 可成电路接触不良、血管栓塞类阻塞。                                      |
| 丧门 | 终结信号、报废、死亡、合同终止           | 要落到“终结信号”而非恐吓式断语。                                        |
| 贯索 | 约束性链接、缠绕、安全带、手铐           | 合同绑定、限制链条、约束关系。                                          |
| 天厄 | 不可抗风险、天灾、外部风险               | 与迁移宫、太岁、官府同看不可控变量。                                    |
| 将军 | 权威行动指令、执行能力                   | 表动员、执行、某方面的能力权威。                                        |
| 喜神 | 快乐能量显化                             | 庆典、烟花、愉悦素、快乐气息。                                          |

## 六、四化能量模型

### 1. 四化总表

| 四化 | 核心动作                                 | 物理模型                         | 裁断口径                                                                                 |
| :--- | :--------------------------------------- | :------------------------------- | :--------------------------------------------------------------------------------------- |
| 化禄 | 放大当前状态、投入、扩散、资源增加       | 趋势被加速或被放大               | 不判断“好”。先问当前状态是什么，再判断放大后是否支持目标。                               |
| 化权 | 推动或压制、主导介入、碰撞、施压、控制   | 外力介入、杠杆、摩擦、强制执行   | 先判定谁飞权、飞向哪里、主体是否顺势。有承载为推动/执行；逆势、见忌或高压则为压迫/反噬。 |
| 化科 | 延缓、回退、修正、化解、蓄满、点亮       | 信息载体、缓冲层、修复机制       | 最显著特性是慢。可表现为文书、公示、背书、缓冲、慢慢转变。                               |
| 化忌 | 终止当前状态、收缩、断点、制动、不再扩张 | 状态被切断、运动被停止、路径终结 | 不判断“坏”。若目标需要终止，则化忌完成目标；若目标需要持续，则化忌阻断目标。             |

### 2. 化禄规则

化禄的基本公式：

> 化禄 = 放大原始星意 + 放大当前能级 + 增加该宫事项的投入。

必须先判断当前状态：

| 当前状态             | 化禄后                                       |
| :------------------- | :------------------------------------------- |
| 高能级、目标需要持续 | 推进、扩张、资源注入                         |
| 高能级、目标需要停止 | 过度推进、难以停下                           |
| 低能级、目标需要持续 | 放大低效、放大慢、虚胖、资源漏失             |
| 低能级、目标需要停止 | 低效状态被放大后，可能反而暴露问题并进入调整 |

示例：

- 天机庙旺化禄：运动/思维/技术路径加速。
- 天机落陷化禄：低速状态被放大，可能不是快，而是更明显地慢、卡、绕。
- 太阴化禄：储存内容被放大；储存快乐则快乐放大，储存烦恼则烦恼放大。

### 3. 化权规则

化权的基本公式：

> 化权 = 现实主导力介入 + 推动/压制分流 + 摩擦 + 控制权测试。

化权不是固定增强。真正判断是：

- 推动
- 还是压制

判断顺序：

| 判断项       | 含义                                 |
| :----------- | :----------------------------------- |
| 谁飞权       | 谁在主导现实                         |
| 飞向哪里     | 压谁 / 推谁                          |
| 来源宫角色   | 是主体力量，还是规则、制度、外部系统 |
| 是否竞争问题 | 是否进入筛选、排名、互卷系统         |
| 主体是否顺势 | 顺势则推进，逆势则压制               |
| 是否形成高压 | 是否进入强控、强筛、强摩擦           |
| 是否有忌     | 有忌时，权更容易从推动变成压迫       |

落地判断：

| 条件                                   | 化权表现                     |
| :------------------------------------- | :--------------------------- |
| 主体顺势、宫位能承载、目标需要推进     | 推动、执行、启动、落地       |
| 来源为官禄/父母/规则系统，且主体被筛选 | 压制、审核、强控、排名压力   |
| 竞争问题中多权同步                     | 高压互卷、强筛、强摩擦       |
| 同时见忌或忌已击穿承接面               | 权更容易变成压迫、反噬、卡控 |

示例：

- 贪狼化权：欲望/抓取增强，但需判断是主体主动抓取，还是被欲望/资源系统压迫。
- 破军化权在火位：突破动作强，若阻力过高则成为强压、硬撞或结构重写。
- 天同化权在水位：若顺势可被推动同意；若逆势则表现为被迫、勉强、压力下妥协。
- 太阳化权在水位：外部关注被强行拉起，但若承载不足，容易短暂显化后失去热度。

### 4. 化科规则

化科的基本公式：

> 化科 = 慢 + 修正 + 信息化/名相化 + 缓冲保护。

常见四类表现：

1. 延缓：事情拖慢。
2. 回退：资金、动作、态度回退。
3. 化解：冲突被缓冲、压力被卸掉。
4. 蓄满：慢慢积累到可转变。

特殊规则：

- 化科在水位/木位力量强，在火位/金位较无力。
- 水位/木位化科常需要很长时间才能完成转变。
- 左辅科、右弼科多为激活作用，不宜过度解释。
- 文曲科意义相对有限，偏点亮内容。
- 紫微化科凸显紫微优势；紫微化权反而要检查弱势暴露。

### 5. 化忌规则

化忌的基本公式：

> 化忌 = 终止当前状态 + 定应期 + 触发状态反转。

化忌不是“坏”，而是状态终止。

| 所问目标     | 化忌表现                       |
| :----------- | :----------------------------- |
| 目标需要继续 | 停止、断开、卡住、终止当前趋势 |
| 目标需要停止 | 制动、止损、结束、解除当前状态 |
| 原状态良好   | 良好状态终止                   |
| 原状态不佳   | 不佳状态终止，可能转入改善窗口 |

示例：

- 天机化忌：运动/发展/思维路径终止，可用于断应期。
- 交通事故场景：需要刹车时，天机化忌是制动完成。
- 学习状态：天机庙旺表示学习能力强、思维活跃；化忌则学习停滞、思维中断。
- 大运天机化忌可反推人生重大变化期。

## 七、能级模型

### 1. 基础能级

| 星情结构 | 数值 | 状态                                 |
| :------- | :--- | :----------------------------------- |
| 庙/旺    | 7-6  | 高能量、可承载、可持续、形态完整     |
| 得/利/平 | 5-4  | 中等能量、局部可用、需验证条件       |
| 不/陷    | 2-1  | 低能量、承载不足、形态变形、容易漏失 |

扩展规则：

- 化禄可突破 7 级上限，强势状态可达 10-14 的放大级别。
- 弱陷状态可能低于 1，进入 0.x 的微弱状态。
- 能级不是吉凶，而是承载力、速度、完整度、可持续度。

| 化权 | 掌控力可落地，执行有成果         | 有推动但摩擦明显   | 过压、越权、虚张声势、反噬           |

| 化忌 | 强制制动，压力可消化，状态可切换 | 部分阻断，需看应期 | 系统停摆、承载击穿、路径中断         |

## 八、组合算法

### 1. 组合优先级

裁断时按以下顺序合成：

1. 所问事项：要判断什么。
2. 宫位：事情发生在哪个领域。
3. 主星：主图像。
4. 小星：细节、形状、材质、数量、噪音、缺口。
5. 庙旺落陷：承载力和完整度。
6. 四化：变化、调级、应期。
7. 三方四正/相关宫：路径连接。

### 2. 主星 + 小星

主星定对象，小星改形态。

| 组合        | 成像                         |
| :---------- | :--------------------------- |
| 七杀 + 左辅 | 多条线                       |
| 七杀 + 陀罗 | 缠绕线团、绕线               |
| 七杀 + 地劫 | 断线、线性结构缺口           |
| 七杀 + 地空 | 线鼓起来、平面鼓包           |
| 巨门 + 地劫 | 门洞、漏洞、说空话、沟通缺失 |
| 太阴 + 铃星 | 苦水、储存烦恼               |
| 太阴 + 天喜 | 糖水、储存快乐               |
| 天机 + 地劫 | 白费力气、运动空耗、路径缺口 |
| 太阳 + 地劫 | 照见但漏看、关注但有缺口     |
| 贪狼 + 地劫 | 欲望落空、需求缺口           |
| 武曲 + 地劫 | 钱财损失、硬物破损           |
| 破军 + 地劫 | 突破失败、动作打空           |
| 天府 + 地劫 | 区域变空、本应有而没有       |
| 天梁 + 火星 | 火柱子、支柱带热/急/火性     |

### 3. 四化 + 组合

四化作用于组合后的图像。

公式：

> `(主星 + 小星 + 宫位场景 + 能级) × 四化 = 变化结果`

示例：

- 七杀地劫化忌：线性缺口状态被终止，可能表现为断线节点明确、该线停用、发展线中断。
- 太阴铃星化禄：储存的烦恼被放大。
- 天机地劫化禄：空耗的运动被放大，越动越白费力气。
- 巨门地劫化科：漏洞/沟通缺口进入修复、解释、文书化过程，但速度慢。

## 九、小星 + 四化成本函数

### 1. 小星三层本质

小星不是单纯的附加说明，而是作用在主星路径上的成本函数。

```text
小星 = 场域特性（Field） + 运行机制（Mechanism） + 代价函数（Cost）
```

| 维度     | 含义                         | 裁断用法                                         |
| :------- | :--------------------------- | :----------------------------------------------- |
| 场域特性 | 该宫位的气候、环境、背景色   | 判断此宫是稳定、混乱、隐性、过度、缺失还是噪音场 |
| 运行机制 | 能量在此如何运作             | 判断路径是卡、快、绕、断、漏、散、变还是被遮蔽   |
| 代价函数 | 完成同一结果要额外付出的成本 | 判断时间成本、路径成本、认知偏差成本、结构风险   |

对齐规则：

- 大星定框架。
- 小星定细节。
- 四化定变化与应期。
- 小星负责把“细节”升级为可计算的效率、摩擦和结构风险。

### 2. 小星四类通用模型

裁断时，所有小星必须先归入至少一种类型。
同一小星可因宫位、组合、问题域而兼具多类，但输出时要说明主导类型。

| 类型                       | 关键词                             | 代表星曜                                   | 通用规则                                 | 成本表现         |
| :------------------------- | :--------------------------------- | :----------------------------------------- | :--------------------------------------- | :--------------- |
| 阻力型（Resistance）       | 卡、拖、反复、消耗、噪音、低频干扰 | 陀罗、擎羊、铃星、阴煞                     | 使路径产生摩擦、卡顿、延迟或难以直接推进 | 时间成本上升     |
| 流动型（Variation）        | 变化、切换、多路径、不稳定、移动   | 天马、天机类结构、右弼                     | 使路径产生多路径、不稳定、转向或持续变动 | 路径成本上升     |
| 染色型（Marker）           | 真假、情绪、标签、名相、隐性性质   | 天虚、天喜、病符、文曲忌、红鸾、咸池、天姚 | 改变结果性质，不优先改变路径结构         | 认知偏差成本上升 |
| 击穿型（Structural Break） | 断裂、崩塌、缺失、耗尽、结构改写   | 地劫、天空、大耗、截空、丧门               | 直接改变结构，不只是过程修饰             | 结构风险上升     |

补充归类：

| 星曜 | 默认类型         | 说明                                         |
| :--- | :--------------- | :------------------------------------------- |
| 地空 | 染色型 / 击穿型  | 轻则过度、多余、鼓起；重则空亡、结构空转     |
| 地劫 | 击穿型           | 本应有而没有，坑洞、断裂、缺口               |
| 火星 | 流动型 / 阻力型  | 速度、温度、光亮；过强时造成急躁、过热、灼伤 |
| 文昌 | 染色型 / 流动型  | 传播路径、偏斜、文书载体                     |
| 文曲 | 染色型           | 内容性质、文字数据、契约内容                 |
| 左辅 | 流动型           | 数量增加、多条路径、多层辅助                 |
| 右弼 | 流动型           | 转向、更新、再一次、路径改变                 |
| 禄存 | 击穿型 / 阻力型  | 块状堆积，可能形成堵塞或沉重成本             |
| 解神 | 击穿型的反向修复 | 分解、解除、终止旧结构                       |
| 天刑 | 阻力型 / 击穿型  | 规则切割、手术、惩罚、可控伤害               |

### 3. 通用计算公式

```text
最终表现 = 四化方向 × 主星承载 × 落点宫位容器 × 小星修饰系数
```

其中：

```text
小星修饰系数 = 场域特性 + 运行机制 + 成本类型
```

裁断时不得只说“小星不好”。
必须说清楚它增加了哪一种成本。

### 4. 小星作用于四化

#### 化禄：扩散与放大

```text
收益路径 = 化禄 ×（主星当前状态）×（1 - 阻力 + 变动 + 染色）
```

| 小星类型 | 对化禄的作用                                       |
| :------- | :------------------------------------------------- |
| 阻力型   | 收益变慢，资源进入但兑现延迟                       |
| 流动型   | 收益不稳定，资源路径多变或分散                     |
| 染色型   | 收益性质改变，可能变成情绪收益、名义收益、虚假收益 |
| 击穿型   | 放大缺口、空耗、断裂或结构性漏失                   |

示例：

- 太阴铃星化禄：储存的烦恼被放大，收益表现为“苦水增加”。
- 天机地劫化禄：运动空耗被放大，越动越白费力气。
- 贪狼地劫化禄：欲望被放大，但实际满足有缺口。

#### 化权：推进与施压

```text
推进路径 = 化权 ×（主星执行力）×（路径偏移 + 阻力 + 结构承压）
```

| 小星类型 | 对化权的作用                         |
| :------- | :----------------------------------- |
| 阻力型   | 推进卡顿，越推摩擦越大               |
| 流动型   | 推进方向变化，可能转向、换人、换路径 |
| 染色型   | 推进带有标签、情绪、名相或误判       |
| 击穿型   | 强制重构，可能直接改写结构           |

示例：

- 破军地劫化权：强行动作打到缺口上，突破可能变成结构重写或突破失败。
- 巨门地劫化权：强行打开通道，但通道本身有洞，易变成权限/沟通漏洞。

#### 化科：修正与缓冲

```text
修正路径 = 化科 ×（延迟 + 多轮修正 + 信息化）
```

| 小星类型 | 对化科的作用                         |
| :------- | :----------------------------------- |
| 阻力型   | 修正变慢，流程拖延                   |
| 流动型   | 反复修正，多次变更版本或路径         |
| 染色型   | 修正偏表面、名义、文书、标签化       |
| 击穿型   | 修正结构缺口，若承载不足则只留下补丁 |

示例：

- 巨门地劫化科：漏洞进入解释、修复、文书化流程，但速度慢。
- 文曲忌遇科：内容层面被修正，但容易停留在名相或文本表面。

#### 化忌：收缩与终止

```text
收缩路径 = 化忌 ×（当前状态终止）×（小星成本放大）
```

| 小星类型 | 对化忌的作用                   |
| :------- | :----------------------------- |
| 阻力型   | 问题拖长，终止过程不干脆       |
| 流动型   | 问题扩散，终止点移动或路径外溢 |
| 染色型   | 问题性质被误读，容易贴错标签   |
| 击穿型   | 直接崩塌、断裂、清空或结构终止 |

示例：

- 七杀地劫化忌：线性缺口被触发为断线节点，发展线中断。
- 天机陀罗化忌：运动/思维被反复缠住后终止，表现为卡住很久才停。

### 5. 小星组合通用规则

任意小星组合都按场域叠加处理，不得只背固定组合。

```text
小星组合 = 场域叠加（Field Overlay）
最终场域 = ∑（各小星场域特性）
```

示例：

```text
流动型（天马） + 阻力型（陀罗）
= 变化中卡顿
= 多路径 + 摩擦
= 曲线推进结构
```

裁断输出：

> 该路径并非完全不能动，而是在变化中反复卡住，需要绕行、等待或多次调整。

### 6. 成败判定

```text
结果 = 四化方向（主导）
      × 主星能级（承载）
      × 落点宫位（容器）
      × 小星成本（效率/代价）
```

小星阻力不必然导致失败。
若满足以下条件，阻力可转化为筛选、优化、训练或防错机制：

```text
四化 ∈（化禄 / 化权 / 化科）
AND 主星能级 ≥ 平
AND 落点宫位可承载
AND 所问目标允许延迟、试错或多轮修正
```

转化规则：

| 小星成本     | 可转化为                       |
| :----------- | :----------------------------- |
| 时间成本     | 筛选机制、训练周期、沉淀过程   |
| 路径成本     | 多方案试错、路线优化、转向机会 |
| 认知偏差成本 | 标签校正、名义确认、信息澄清   |
| 结构风险     | 重构机会、止损点、旧结构清除   |

若不满足承载条件，小星成本会从“修饰”升级为“拖垮路径”的主导因素。

### 7. 小星表达模板

裁断中必须使用以下句式之一：

```text
该路径在【宫位】中，受【小星类型】影响，
表现为【运行机制】，从而增加【成本类型】。
```

```text
该星曜原始成像为【主星图像】，
小星将其修饰为【细节图像】，
四化再使该图像进入【放大/推进/修正/终止】状态。
```

示例：

> 该路径在官禄宫中，受阻力型小星影响，表现为反复卡顿，从而增加时间成本。

> 天机原始成像为运动路径，陀罗将其修饰为绕圈与缠住，化忌再使该路径进入反复卡住后的终止状态。

### 8. 禁止错误

- 禁止把某个小星固定为“坏”。
- 禁止把某个小星固定为“好”。
- 禁止把某个组合当作唯一结构，例如只认“天马 + 陀罗”。
- 禁止忽略小星类型分类直接下结论。
- 禁止只说“有阻碍”，必须说明阻碍属于时间成本、路径成本、认知偏差成本还是结构风险。
- 禁止小星越级覆盖主星；除非击穿型小星已经造成结构重写。

### 叠宫时空投影协议

#### 叠宫本质定义 (Static Projection)

- **核心定义**：叠宫是不同时空层（原局 / 大运 / 流年）在同一物理宫位标签上的**静态重叠投影**。
- **物理性质**：
  - **叠宫 = 定位器**：仅用于锁定本年度能量最集中的“物理战场”与“人生领域”。
  - **叠宫 ≠ 因果律**：叠宫本身不代表事件发生，也不产生能量流动。
  - **独立裁断禁区**：禁止仅凭叠宫组合断定吉凶成败。必须配合“飞四化”路径判定最终落地结果。

#### 三位一体穿透逻辑 (Spatio-temporal Hierarchy)

解析时必须遵循 **[流年 > 大运 > 原局]** 的层级压制顺序，构建事件触发链条：

| 时空层级      | 角色定位   | 物理意义                           |
| :------------ | :--------- | :--------------------------------- |
| **流年 (人)** | **触发点** | 当下的外部诱因，发生了什么事？     |
| **大运 (天)** | **环境层** | 阶段性的气候背景，这十年在干什么？ |
| **原局 (地)** | **本质层** | 先天的结构根基，最终作用于我什么？ |

- **[解析范式]**：`外部[流年宫]诱发 → 激活阶段性[大运宫]状态 → 最终压制/作用于[原局宫]本质。`

#### 叠宫实战判定标准

- **聚焦效应**：同宫叠三层（如：原命+大命+流命）判定为**人生重大转折节点**。
- **路径效应**：根据宫位象义形成链条（如：命→财→田），判定为**事件演化轨迹**（如：人生抉择导致财务变动，最终落地为资产配置）。
- **损益判定**：
  - **叠宫定位**：确定“哪里会出事”。
  - **飞四化定性**：通过飞入/飞出路径判定“会不会出事、怎么出”。

## 十三、【高阶判定】能量密度与权重压制准则

**核心原则：抓大放小，实相优先。禁止被低频噪点干扰核心裁断。**

### 能量百分比（能级）的物理定性

- **🎯 目标宫位覆盖协议 [最高权重]：** 哪怕能级不高，只要该宫属于当前模式的目标宫位，即 **主卦宫 / 十分钟卦 / 分钟卦 / 流年宫 / 大运宫 / 来因宫**，都必须按最高权重进入主线分析。
  - **解卦要求：** 目标宫位优先级高于单纯能级百分比。低能级只说明显像弱、物理化慢、受干扰多，不代表可以降权或忽略。
- **📡 80% - 100% [核心指令/实相层]：** \* **物理意义：** 高纯度能量撞击，具备不可抗拒的“强制力”与“确定性”。
  - **解卦要求：** 必须作为首要切入点。这是守护神/高维系统钉死的人生“道钉”。
- **⚖️ 40% - 70% [常规流转/波动层]：** \* **物理意义：** 稳定的日常能量交换，代表持续性的状态。
  - **解卦要求：** 作为背景描述，支撑主线逻辑。
- **🔈 15% 以下 [能量噪点/虚化层]：** \* **物理意义：** 物理涟漪或背景噪音，显像极弱，易被干扰。
  - **解卦要求：** 除非涉及微观预警，否则在总论中予以忽略，避免误导。

### 载体（星）与场域（宫）的辨证逻辑

- **场域 (宫位)：** 定义事件发生的“维度”与“层级”（如：福德宫定义为灵魂深处）。
- **载体 (星曜)：** 定义事件的“具体物理形态”（如：文昌定义为文字/信息）。
- **判定准则：** 只有当**高能级四化（80%+）**作用于具体的**载体星**时，沟通才具备“可观测的物理显像”。

## 十四、【动态应卦】阴阳损益对冲算法

**核心原则：应卦非“吉凶选择”，而是“能量损耗最小化”的路径规划。**

#### 能量位移与置换 (Energy Displacement)

- **逻辑：** 当高能级化忌（D）出现在“结果位”（如迁移宫、财帛宫）时，物理收缩不可避免。
- **策略：** **“主动受力，柔性对冲”**。
  - **应卦公式：** `[主动执行星曜的负向属性] → [消耗化忌的收缩能量] → [保护核心场域不受损]`。
  - **范例：** 贪狼忌在迁移宫（外部欲望受阻）→ 主动进行“禁欲/苦修”（主动收缩欲望）→ 换取福德宫紫微科（精神高度清明）的实相。

#### 高能级特殊路径字典 (Manifestation Dictionary)

- **【天恩委任】父母飞紫微权(90%)入福德：** 高维意志强行写入灵魂架构。主：天命感、精神高标、不可撼动的内核。
- **【硬核保镖】官禄飞天梁权(90%)入子女：** 行为路径受到物理级的强制保护/干预。主：规则止损、强制修正、不容质疑的避险指令。
- **【信息脉冲】文昌/天机高能级碰撞：** 守护神通过文字、逻辑、数据流直接通讯。主：精准直觉、书面启示。

## 十五、后台执行自检准则

- [ ] **查源头**：解析飞出前，必须先看这个宫位的“飞入”数据，确定谁是肇事者。
- [ ] **保全项**：输出中必须包含 A/B/C/D 四个小节，禁止跳过任何一项。
- [ ] **定显像**：可以使用“吉、凶、好、坏”，但必须使用物理词汇（如：断裂、覆盖、精密、空洞）进行说明。
- [ ] **能级过滤：** 是否已锁定 80% 以上的能量块？是否已被 5% 的噪点带偏？
- [ ] **场域/载体分离：** 是否明确了这股能量是在“哪里”发生，以及通过“什么媒介”显像？
- [ ] **应卦策略：** 结论是否给出了具体的“能量置换动作”？（即：如何通过主动损耗来规避被动打击）。

# 奇门：辅助场协议

## 一、核心定位（最高优先级）

奇门：

不是因果系统。

也不是事件成立系统。

奇门在紫占中的唯一定位：

> 「天地运行场状态观察层」

作用：

用于观察：

- 当前天地场是否开放
- 路径推进是否顺滑
- 信息是否流通
- 空间是否阻塞
- 主导权是否真实
- 推进是否只是表面动作
- 现实是否存在“假推进”

---

## 二、紫占主次铁律（强制）

紫占中：

### 飞四化

决定：

- 为什么发生
- 谁推动
- 能量从哪里来
- 最终落向哪里
- 是否真正成立

属于：

> 唯一合法因果层

---

### 奇门

只能观察：

- 事情怎么推进
- 推进是否顺
- 场域是否开放
- 是否存在阻力
- 是否只是表面热闹

属于：

> 运行环境层

---

## 三、奇门禁止事项（强制）

奇门禁止：

- 替代飞四化
- 定义事件成立
- 修改飞化方向
- 修改发源宫
- 修改收敛宫
- 推翻紫占裁断
- 单独定义吉凶
- 脱离紫占单独成卦

---

## 四、奇门在紫占中的接入顺序

紫占正式裁断流程：

### 1. 定太极点

↓

### 2. 定用宫

↓

### 3. 看宫星成相

↓

### 4. 看飞四化因果

↓

### 5. 看追化来源

↓

### 6. 看显化位

↓

### 7. 奇门辅助场校验

↓

### 8. 最终现实落地

---

注意：

奇门永远位于：

> 「飞四化之后」

因为：

奇门不能决定因果。

只能观察：

> 因果进入现实后的推进环境。

---

## 五、奇门核心定义（紫占化）

## 奇门的本质

奇门不是“神秘力量”。

而是：

> 「天地运行时，现实场的开合状态」

类似：

- 空气阻力
- 空间开放度
- 通道通畅度
- 人群配合度
- 信息流动状态

---

因此：

同一个飞四化结果：

可以：

- 很顺推进
- 很难推进
- 卡住推进
- 假装推进
- 反复推进

这部分：

由奇门辅助观察。

---

## 六、八门现实场协议（核心）

### 开门

定义：

现实通道打开。

现实表现：

- 容易接触
- 容易谈成
- 外部愿意配合
- 门槛下降
- 现实开始真正接通

紫占融合：

适合：

- 飞禄
- 飞权
- 实际落地

---

### 休门

定义：

现实进入缓冲。

现实表现：

- 暂停
- 等待
- 修整
- 不急推进
- 事情未死但放慢

注意：

休门不是失败。

而是：

> 「天地场要求暂停消化」

---

### 生门

定义：

现实存在持续成长空间。

现实表现：

- 可以继续发展
- 有后续空间
- 能继续养大
- 有长期推进性

注意：

生门不等于已经成功。

只是：

> 「具备继续成长条件」

---

### 伤门

定义：

推进伴随消耗。

现实表现：

- 很累
- 摩擦大
- 消耗资源
- 有代价
- 边推进边受损

紫占融合：

尤其注意：

- 飞忌
- 冲忌
- 铃星
- 擎羊
- 火铃

是否同步出现。

---

### 杜门

定义：

现实通道封闭。

现实表现：

- 沟通卡住
- 对方不回应
- 审批阻塞
- 信息封闭
- 外部不开放

注意：

杜门：

不是结果失败。

而是：

> 「现实暂时不通」

---

### 景门

定义：

现实进入“外观放大”。

现实表现：

- 包装增强
- 气氛很好
- 表面热闹
- 看起来很像成功
- 宣传感强

紫占铁律：

景门最容易出现：

> 「假推进」

因此：

必须结合飞四化确认：

是否真的承接。

---

### 惊门

定义：

现实进入不稳定扰动态。

现实表现：

- 反复
- 临时变化
- 突发情况
- 一惊一乍
- 节奏断裂

紫占融合：

惊门最容易：

- 改时间
- 临时取消
- 快成又变
- 信息突然逆转

---

### 死门

定义：

现实推进冻结。

现实表现：

- 不再展开
- 停摆
- 卡死
- 无法继续推进
- 外部彻底失去反应

注意：

死门：

只能定义：

> 「现实推进冻结」

不能单独定义：

> 「最终一定失败」

因为：

飞四化才是因果层。

---

## 七、值符协议（紫占融合）

### 值符

定义：

> 当前现实真正掌控局势的一方。

不是名义主导。

而是：

真正能拍板的人。

---

### 值符落空亡

定义：

主导权失真。

现实表现：

- 表面有人负责
- 实际没人拍板
- 看似推进
- 实际无人真正控制局势

紫占融合：

特别容易出现：

- 景门假推进
- 飞禄但不落地
- 官面说可以
- 现实没人执行

---

## 八、值使协议（紫占融合）

### 值使

定义：

真正负责推进的人。

---

### 值符 ≠ 值使

定义：

决策层与执行层分裂。

现实表现：

- 老板同意但团队不动
- HR推进但业务部门卡
- 客户愿意但财务不放
- 有人说可以但没人干

---

## 九、空亡协议（强制）

空亡：

只能定义：

> 「现实存在落空感」

禁止：

直接定义失败。

---

### 空亡现实表现

- 有名无实
- 说了不做
- 看起来存在
- 实际接不到
- 表面推进
- 实际承接为空

---

### 紫占融合铁律

若：

飞四化成立

但：

奇门空亡

则：

定义为：

> 「因果存在，但现实承接失真」

---

## 十、驿马协议（紫占融合）

驿马：

定义：

现实进入高流动状态。

现实表现：

- 异地
- 高频变化
- 来回移动
- 远程推进
- 节奏很快

---

### 驿马 + 死门

定义：

反复折腾。

现实表现：

- 一直跑
- 一直变
- 一直动
- 但始终无法真正落地

---

## 十一、假推进协议（核心新增）

若：

紫占因果存在。

同时：

出现：

- 景门
- 惊门
- 杜门
- 空亡

则必须检查：

> 是否只是“现实看起来在推进”。

---

### 假推进现实表现

- 口头答应
- 表面热情
- 一直说快了
- 看似有戏
- 一直在聊
- 但始终不真正落地

---

### 紫占铁律

判断真假推进：

必须回到：

- 飞四化是否真正承接
- 是否真正入用宫
- 是否真正形成闭环

奇门：

只能辅助观察：

> 「现实表层状态」

---

## 十二、空间场协议（紫占融合）

奇门允许观察：

- 客场压力
- 异地阻力
- 空间错配
- 地域适配
- 环境开放度

---

但禁止：

修改：

- 飞四化因果
- 最终收敛
- 真实结果

---

## 十三、紫占输出协议（新增强制）

若使用奇门辅助场。

最终输出中必须增加：

### 🧭 奇门现实场状态

#### 当前主门：

（开 / 休 / 生 / 伤 / 杜 / 景 / 惊 / 死）

#### 现实推进状态：

（顺畅 / 卡顿 / 反复 / 冻结 / 表热内空）

#### 主导权状态：

（真实主导 / 主导失真）

#### 执行权状态：

（执行顺畅 / 执行断裂）

#### 是否存在假推进：

（是 / 否）

#### 空间场状态：

（开放 / 阻塞 / 异地压力 / 空间错配）

---

## 十四、最终铁律（最高优先级）

飞四化：

决定：

> 「为什么发生」

奇门：

决定：

> 「现实推进时的天地场状态」

---

紫占中：

真正决定结果的：

永远是：

> 飞四化闭环。

---

奇门只能辅助观察：

- 场是否开放
- 路是否顺
- 人是否真动
- 推进是真是假
- 现实有没有承接

---

禁止：

用奇门：

- 替代紫占
- 推翻飞四化
- 单独定结果
- 单独定成败

---

奇门在紫占中的最终定位：

> 「现实运行场观察层」
