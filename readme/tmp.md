

# 【新增】十二、小星优先级协议（最高优先级）

## 12.1 冲突优先级

若同路径同时存在：

```text
多个小星类别
```

必须按：

```text
击穿型
>
约束型
>
阻力型
>
流动型
>
支撑型
>
染色型
```

执行。

---

## 12.2 原因

因为：

```text
结构破坏
优先于
体验修饰
```

---

## 12.3 示例

```text
夫妻宫：
天喜 + 地劫
```

最终：

❌ 不能断“感情开心”

必须：

```text
关系存在短期快乐，
但结构实际空洞。
```

# 【新增】十三、小星联动协议（核心升级）

## 13.1 联动原则

⚠️ 小星之间：

不是简单叠加。

而是：

```text
动力学耦合
```

---

## 13.2 常见联动

### 阻力型 + 流动型

例如：

```text
陀罗 + 天马
```

表现：

```text
一边移动，
一边卡顿。
```

现实：

* 搬迁反复
* 关系拉扯
* 项目来回修改

---

### 击穿型 + 染色型

例如：

```text
地劫 + 文曲
```

表现：

```text
信息结构空洞
```

现实：

* 合同漏洞
* 数据缺失
* 内容失真

---

### 支撑型 + 化忌

例如：

```text
天魁 + 化忌
```

表现：

```text
虽有压力，
但系统仍有人兜底
```

---
